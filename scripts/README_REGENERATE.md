# 📖 Инструкция по использованию скрипта перегенерации колод (`regenerate_deck_single.py`)

Скрипт `scripts/regenerate_deck_single.py` предназначен для **высококачественной поштучной перегенерации** карточек в выбранной колоде напрямую в облачной базе данных (Supabase).

---

## 🌟 Ключевые возможности

1. **Одиночная генерация максимального качества (Single Generation):**
   * Для каждой карточки формируется подробный структурированный разбор:
     * 🔄 **Лицевая сторона:** исходный вопрос/фраза.
     * 📝 **Обратная сторона:** полный перевод (для тестов — перевод вопроса и всех вариантов с отметкой ✅ верного).
     * 🎯 **Объяснение:** почему именно этот ответ правильный (история, законы, логика).
     * 📖 **Словарный запас:** слова с артиклями, формами и переводом.
     * 💡 **Грамматика:** разбор грамматических правил и конструкций.
     * 🏷 **CEFR Уровень:** автоматическая разметка (A1, A2, B1, B2, C1, C2).
2. **🛡️ Умная защита от лимитов API (Rate Limit / Quota Exceeded):**
   * Если нейросеть возвращает ошибку `429` / `Resource Exhausted`, скрипт не падает, а делает автоматическую экспоненциальную паузу (10с → 18с → 32с → 60с) и повторяет запрос до 6 раз.
3. **💾 Автоматический бэкап:**
   * Перед началом генерации создаётся резервная копия колоды в формате JSON в папке `api/data/backups/`.
4. **🔄 Возобновление работы (`--resume`):**
   * Каждая карточка сохраняется в облачную базу данных сразу же после успешного ответа. В случае остановки процесса (например, `Ctrl+C`) можно продолжить с того же места флагом `--resume`.
5. **🔊 Синтез озвучки (TTS):**
   * Автоматически обновляет аудио через Microsoft Edge TTS.

## 🚀 Быстрый старт (Примеры команд)

Все команды выполняются из корневой папки проекта (`c:\121\Lerne_projekt\tma`):

### 1. Посмотреть список всех доступных колод и их ID
```powershell
python scripts/regenerate_deck_single.py --list-decks
```

### 2. Интерактивный запуск (скрипт покажет список и спросит ID)
```powershell
python scripts/regenerate_deck_single.py
```

### 3. Перегенерировать конкретную колоду целиком
```powershell
python scripts/regenerate_deck_single.py --deck-id 691
```
*(Скрипт покажет параметры, создаст бэкап и запросит подтверждение перед стартом).*

### 4. Автоматический запуск без подтверждения (`-y`)
```powershell
python scripts/regenerate_deck_single.py --deck-id 691 -y
```

### 5. Перегенерировать диапазон карточек (например, с 11 по 290)
```powershell
python scripts/regenerate_deck_single.py --deck-id 691 --start 11 --end 290 -y
```

### 6. Безопасный тест (Dry-Run на первых 3 карточках без записи в БД)
```powershell
python scripts/regenerate_deck_single.py --deck-id 691 --start 1 --limit 3 --dry-run
```

### 7. Продолжить прерванную генерацию (`--resume`)
```powershell
python scripts/regenerate_deck_single.py --deck-id 691 --resume -y
```

### 8. Перегенерировать только пустые карточки (где нет перевода или контекста)
```powershell
python scripts/regenerate_deck_single.py --deck-id 691 --only-empty -y
```

### 9. Перегенерировать без озвучки (быстрее, только текст)
```powershell
python scripts/regenerate_deck_single.py --deck-id 691 --no-audio -y
```

## 📋 Полная таблица параметров

| Параметр | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `--deck-id <ID>` | ID колоды для перегенерации | `None` (интерактивный ввод) |
| `--deck-name "<NAME>"` | Поиск колоды по названию | `None` |
| `--start <N>` | Номер начальной карточки (1-based, например `11`) | `1` (с первой) |
| `--end <N>` | Номер конечной карточки (1-based, например `290`) | До конца колоды |
| `--limit <N>` | Ограничить количество обрабатываемых карточек | Все в диапазоне |
| `--delay <float>` | Пауза между карточками в секундах | `2.0` сек |
| `--max-retries <int>` | Число повторных попыток при лимитах API | `6` |
| `--initial-backoff <float>` | Начальное время ожидания при Rate Limit (сек) | `10.0` сек |
| `--target-lang <код>` | Изучаемый язык (`de`, `en`, `no`) | Язык колоды или `de` |
| `--native-lang <код>` | Родной язык (`ru`, `uk`, `en`) | Из настроек или `ru` |
| `--no-audio` | Отключить генерацию озвучки (TTS) | `False` (озвучка включена) |
| `--only-empty` | Генерировать только карточки с пустым переводом/контекстом | `False` |
| `--resume` | Пропустить карточки, уже готовые в чекпоинте | `False` |
| `--dry-run` | Тестовый прогон в консоли без сохранения в БД | `False` |
| `-y`, `--yes` | Пропустить диалог подтверждения `[Y/n]` | `False` |
| `--list-decks` | Вывести список всех активных колод и завершить работу | `False` |

## 📂 Где хранятся бэкапы?

Перед каждым запуском (кроме `--dry-run`) скрипт делает полный снимок карточек в папку:
```
api/data/backups/deck_<ID>_<ГГГГММДД_ЧЧММСС>.json
```
В файле сохраняются: `id`, `front_text`, `back_text`, `context`, `tags`, `audio_path`, `position`. В случае необходимости данные можно легко восстановить.
