# Тип: Free Text

## WHEN TO USE
Использовать **только для действительно открытых заданий**, где нет и не может быть одного или нескольких заранее зафиксированных ответов:
- личное мнение
- описание картинки/ситуации
- рассказ о себе или опыте
- эссе, рассуждение
- свободный устный или письменный ответ

## WHEN NOT TO USE
- Если существует один или ограниченный набор точных правильных ответов (слово, дата, термин, перевод, грамматическая форма) — **строго использовать `trainer-input`, а не `@free`**.

## FORMAT
- Внутри `::exercise` ставится обязательный маркер `@free`.
- **Блок `BACK` обязателен и не должен быть пустым**: он содержит пример ответа (Musterlösung) или ориентир для самопроверки ученика. Не используйте `CONTEXT` как пример ответа!
- `BACK` для `@free` — это эталонный образец, а не строгая строка для точного совпадения.

```text
FRONT:
::task
Erzählen Sie über Ihre Familie.

::exercise
@free
Beschreiben Sie Ihre Familie in 5-6 Sätzen.

BACK:
(Musterlösung) Ich habe eine große Familie. Meine Eltern heißen Thomas und Maria. Wir leben zusammen in Berlin...

CONTEXT:
Sprechen A2
```

## VALIDATION
- Задание действительно открытое (мнение, эссе, рассказ) без однозначного правильного ответа.
- Маркер `@free` присутствует в `FRONT` внутри `::exercise`.
- `BACK` заполнен и содержит пример/Musterlösung (не пустой!).
- `CONTEXT` содержит тему/уровень, а не пример ответа.
- Внутри `FRONT` нет маркеров `[[ ]]` или `{ }`.
