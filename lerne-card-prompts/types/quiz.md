# Quiz

Выбор одного правильного ответа из отдельного списка под вопросом; inline-выбор — Trainer Choice.

В теле упражнения пиши вопрос, пустую строку, затем минимум два непустых варианта с новой строки без пустых строк между ними. Ровно один вариант начинается с `*`. Не смешивай варианты с Trainer-пропусками и не добавляй `@quiz`: тип определяется структурой. BACK — перевод вопроса/обрабатываемой фразы или ответ по смыслу задания.

```text
FRONT:
::task
Beantworten Sie die Frage.
::exercise
Wann begann die Französische Revolution?

1812
*1789
1776
1799
BACK:
Когда началась Французская революция?
CONTEXT:
В 1789 году, с взятием Бастилии.
```
