# Тип: Quiz

## WHEN TO USE
Классический тест с одним правильным ответом из списка. Варианты идут блоком под вопросом, а не встраиваются в текст.

## FORMAT
Вопрос пишется текстом. **Между вопросом и вариантами ОБЯЗАТЕЛЬНА пустая строка** (парсер по ней отделяет вопрос от вариантов). Варианты ответа идут с новой строки, без пустых строк между ними. Перед правильным ответом ставится `*`.

```text
FRONT:
::task
Beantworten Sie die Frage.

::exercise
Wann begann die Französische Revolution?

1812
*1789
1776
1799

BACK:
Когда началась Французская революция?

CONTEXT:
Революция началась в 1789 году со взятия Бастилии.
```

## WHEN NOT TO USE
Не используйте, если выбор нужно сделать прямо внутри предложения (для этого есть Trainer Choice).

## VALIDATION
- Ровно один вариант отмечен `*`.
- Между вопросом и первым вариантом есть пустая строка; между вариантами пустых строк нет.
- Звездочка стоит в начале строки.
