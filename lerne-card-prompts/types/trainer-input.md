# Тип: Trainer Input

## WHEN TO USE
Когда ученик должен самостоятельно вписать/впечатать ответ с клавиатуры. Отлично подходит для грамматики (спряжение глаголов, склонение), перевода конкретных слов внутри предложения.

## WHEN NOT TO USE
- Не использовать для открытых творческих ответов без однозначного решения — для этого использовать free-text (@free).
- Не использовать, если требуется исключительно выбор из готовых вариантов (для этого есть Trainer Choice или Quiz).

## FORMAT
Внутри `FRONT` правильный ответ оборачивается в двойные квадратные скобки `[[ответ]]`. 
- Если нужно вписать несколько частей, размечайте все необходимые ответы: `Er [[war]] nach Hause [[gegangen]].`
- Для `[[...]]` содержимое считается одним точным ответом. **Не использовать внутри него `|` для альтернатив (НЕЛЬЗЯ: `[[war|ist]]`)**.
- **Комбинирование**: Trainer Input и Trainer Choice можно и нужно комбинировать, если исходное задание требует обеих механик. Это всё ещё один тип `trainer` (не создавайте `trainer-mixed`).

### Пример одиночного Trainer Input:
```text
FRONT:
::task
Ergänzen Sie die richtige Form.

::exercise
Er [[war]] nach Hause [[gegangen]].

BACK:
war ... gegangen

CONTEXT:

```

### Пример комбинированного Trainer (Input + Choice):
```text
FRONT:
::task
Wählen Sie das passende Wort und ergänzen Sie die Form.

::exercise
{*Als|Wenn} ich nach Hause kam, [[hatte]] sie schon [[gegessen]].

BACK:
Als ... hatte ... gegessen

CONTEXT:
```

## VALIDATION
- Убедитесь, что все слова, требующие ввода, обернуты в `[[ ]]`.
- Внутри `[[ ]]` нет символа `|`.
- `BACK` содержит ожидаемый ответ (для справки ученика при перевороте карточки).
- Если задание содержит и выбор, и ввод — обе механики оформлены корректно в одной карточке.
