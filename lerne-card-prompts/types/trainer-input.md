# Тип: Trainer Input

## WHEN TO USE
Когда ученик должен самостоятельно вписать/впечатать ответ с клавиатуры. Отлично подходит для грамматики (спряжение глаголов, склонение), перевода конкретных слов внутри предложения.

## WHEN NOT TO USE
Не использовать для длинных развернутых эссе или свободных ответов (Free Text пока отключен!). Не использовать, если нужно выбрать из готовых вариантов.

## FORMAT
Внутри `FRONT` правильный ответ оборачивается в двойные квадратные скобки `[[ответ]]`. 
Если нужно вписать несколько частей, размечайте все необходимые ответы.

```text
FRONT:
::task
Ergänzen Sie die richtige Form.

::exercise
Er [[war]] nach Hause [[gegangen]].

BACK:
war ... gegangen

CONTEXT:
Plusquamperfekt B1
```

## VALIDATION
- Убедитесь, что все слова, требующие ввода, обернуты в `[[ ]]`.
- `BACK` должен содержать ожидаемый ответ (для справки ученика при перевороте карточки).
