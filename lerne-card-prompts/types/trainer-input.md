# Trainer Input

Самостоятельный ввод точного ответа: слова, формы или перевода. Для свободного рассказа/мнения используй Free Text.

Правильный ответ в FRONT оборачивай в `[[ответ]]`; размечай все части, которые ученик должен ввести. Содержимое — один непустой точный ответ, без альтернатив через `|`: `[[war|ist]]` недопустимо. При нескольких допустимых формулировках уточни контекст либо выбери Choice с отмеченными ответами. BACK — перевод обрабатываемой фразы целиком.

Сочетание с выбором и общий пример Trainer — в [trainer-choice.md](trainer-choice.md).

```text
FRONT:
::task
Ergänzen Sie die richtige Form.
::exercise
Er [[war]] nach Hause [[gegangen]].
BACK:
Он ушёл домой.
CONTEXT:
Plusquamperfekt образуется из war/hatte и Partizip II.
```
