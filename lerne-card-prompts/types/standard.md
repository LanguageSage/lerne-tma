# Тип: Standard

## WHEN TO USE
Обычные двусторонние карточки без специальной интерактивной разметки. Идеально для простых пар терминов, вопросов-ответов или фактов.

## WHEN NOT TO USE
Не используйте, если ученику нужно ввести текст с клавиатуры, собрать фразу или выбрать вариант ответа.

## FORMAT
Обычный текст без специальной разметки (только маркеры уровня 2, если нужны).

```text
FRONT:
::task
Was ist die Hauptstadt von Deutschland?

BACK:
Berlin

CONTEXT:

```

## VALIDATION
- В `FRONT` нет маркеров вроде `[[ ]]`, `{ | }`, `@match` и т.д.
- `BACK` содержит правильный прямой ответ.
