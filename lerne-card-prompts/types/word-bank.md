# Тип: Word Bank

## WHEN TO USE
Заполнение пропусков в тексте из предоставленного банка слов. Слова перетаскиваются в дырки.

## FORMAT
Используется обязательный маркер `@wordbank`. 

### Формат ID пропусков:
- Пропуски обозначаются как `<<id>>`.
- **Допустимые символы в ID**: латинские буквы (`a-z`, `A-Z`), цифры (`0-9`), дефис `-`, подчеркивание `_`. **Без пробелов**.
- Примеры валидных ID: `<<31>>`, `<<a>>`, `<<B>>`, `<<1a>>`, `<<gap-1>>`, `<<gap_1>>`.
- **Правило нумерации**:
  - Если учебник уже использует номера или буквы для пропусков — **сохраняйте их**.
  - Если пропуски в упражнении никак не обозначены — агент сам назначает: `<<1>>`, `<<2>>`, `<<3>>`...
  - ID — это просто техническая связь между пропуском в тексте и строкой в `BACK`, а не обязательно оригинальный номер из учебника.

### Блок вариантов `@options`:
- Ниже текста идет строка `@options`, где через ` | ` перечислены все доступные варианты (включая дистракторы/лишние слова).

### Блок `BACK`:
- В `BACK` каждый пропуск расшифровывается в формате `id=Ответ`:
  - `31=NACH`
  - `a=AUF`
  - `gap-1=MIT`

```text
FRONT:
::task
Ergänzen Sie die Wörter.

::exercise
@wordbank
Ich fahre <<31>> Berlin.
Ich warte <<32>> den Bus.

@options
NACH | AUF | FÜR | MIT

BACK:
31=NACH
32=AUF

CONTEXT:
Präpositionen B1
```

## WHEN NOT TO USE
- Не использовать, если ученик должен впечатать ответ руками без подсказок (это Trainer Input).
- Не использовать для выбора одного варианта из 2-3 внутри одного предложения (для этого есть Trainer Choice).

## VALIDATION
- `::options` (из Уровня 2) и `@options` (синтаксис Word Bank) не перепутаны! Для банка слов используется строго `@options`.
- Маркер `@wordbank` присутствует (не `@word_bank`!).
- Пропуски оформлены строго как `<<id>>`. Внутри ID нет пробелов.
- Все ID уникальны (нет двух одинаковых `<<id>>` в одном тексте).
- Соответствие 1-к-1: каждый `<<id>>` из текста имеет ровно одну строку `id=Ответ` в блоке `BACK`, и в `BACK` нет лишних ID.
- Каждый ответ из `BACK` присутствует среди вариантов в `@options`.
- Если один ответ повторяется в нескольких пропусках, в `@options` должно быть достаточное количество его копий (или вариант должен быть доступен).
