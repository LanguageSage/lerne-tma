# Word Bank

Заполнение пропусков связного текста из общего банка слов. Для ввода без банка используй Trainer Input, для локального выбора — Trainer Choice.

- После отдельной строки `@wordbank` пиши текст с пропусками `<<id>>`. ID уникальны и содержат только `a-z`, `A-Z`, `0-9`, `-`, `_`, без пробелов: `31`, `a`, `1a`, `gap-1`, `gap_1`. Сохраняй номера/буквы исходника; иначе назначай 1, 2, 3…
- После текста ставь `@options` отдельной строкой, затем варианты через ` | `, включая дистракторы. Каждый вариант используется один раз: для повторяющегося ответа нужны отдельные копии в банке.
- BACK содержит только ключи `id=Ответ`, по одному на строке. Каждому пропуску соответствует ровно один ключ; лишние и повторные ID запрещены. Ответ непустой и присутствует в банке.
- Перевод и правило помещай в CONTEXT. Не смешивай пропуски с `[[...]]`, `{...}` или незавершёнными `<< >>`.

```text
FRONT:
::task
Ergänzen Sie die Wörter.
::exercise
@wordbank
Ich fahre <<31>> Berlin.
Ich warte <<32>> den Bus.

@options
NACH | AUF | FÜR | MIT
BACK:
31=NACH
32=AUF
CONTEXT:
Я еду в Берлин. Я жду автобус.
С городами — nach; warten auf + Akkusativ.
```
