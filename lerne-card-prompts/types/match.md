# Match

Сопоставление пар: слово/перевод, термин/определение, начало/конец предложения. Для сборки одной фразы используй Puzzle.

После отдельной строки `@match` пиши минимум две непустые пары `левая часть => правая часть`, каждую с новой строки. Инструкции выноси в `::task`. Не используй внутри частей пары `=>`, `->`, `—` или `=`: парсер воспринимает их как разделители. BACK — перевод пар или пояснение.

```text
FRONT:
::task
Ordnen Sie die Wörter zu.
::exercise
@match
Apfel => apple
Haus => house
Baum => tree
BACK:
Яблоко, дом, дерево.
CONTEXT:
Базовая лексика.
```
