# Паттерн: Сырой текст (Raw Text)

## ЦЕЛЬ
Понять, как структурировать сырой текст, статью, диалог или список слов перед выбором типа карточки.

## АНАЛИЗ ИСХОДНИКА
1. **Не придумывать лишнего**: По умолчанию **НЕ придумывайте новые вопросы и упражнения**, которых нет в тексте. Сохраняйте механику исходного материала. Новые проверочные задания создавайте **только если пользователь прямо попросил** об этом в промпте.
2. **Текст для чтения**: Если дан текст для чтения с вопросами, текст помещается в `::source`, а реальные вопросы из материала оформляются соответствующим типом (`quiz`, `trainer-choice` и т.д.).
3. **Словарь / пары**: Если дан готовый список слов с переводом, оформите их как `match` (группами по 3-5 пар) или отдельные карточки `trainer-input` / `standard`.
4. **Разделение**: Каждое отдельное задание оформляется как независимая карточка и отделяется строкой `<<<LERNE_CARD>>>`.
