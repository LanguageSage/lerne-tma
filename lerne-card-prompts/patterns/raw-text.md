# Источник: текст, статья, диалог или словарь

- Текст с вопросами: необходимый фрагмент чтения — в `::source`, вопросы — в теле упражнения.
- Текст без заданий: подбирай карточки по цели пользователя. Для практики самостоятельно выделяй проверяемые факты, лексику или конструкции; для чтения и запоминания сохраняй соответствующее назначение.
- Готовый словарь: небольшие группы Match (например, 3–5 пар) либо отдельные Standard/Trainer Input по требуемому действию ученика.
- Не обрезай контекст, необходимый для ответа; независимые задания разделяй, связный материал сохраняй вместе.
