# Источник: теория и объяснения

Различай чтение правила и тренировку его применения. Для чтения используй [Theory](../types/theory.md); для практики самостоятельно превращай правило в подходящее упражнение по цели пользователя, даже если готовых заданий нет. Существующую Theory обрабатывай по правилам её типа.

## Подбор механики

| Учебная цель | Подходящая механика |
| --- | --- |
| Различить значения, факт/гипотезу, оттенки вежливости | Quiz с трактовками или Trainer Choice в контексте |
| Освоить спряжение, формы и окончания | Match, Trainer Input или Choice |
| Применить порядок слов | Puzzle для сборки фразы; Choice для выбора порядка |
| Понять сложное правило или разбор | Theory с развёрнутым объяснением; отдельная практика, если нужна |

Это ориентиры, а не обязательное назначение типа. Проверяй ключевое правило, а не случайное слово. В CONTEXT объясняй причину ответа и существенное отличие альтернатив; сохраняй важные исключения и смысловые нюансы. Объём определяет содержание, а не требование «очень коротко».

## Примеры адаптации

Различие значений — Quiz:

```text
FRONT:
::task
Bestimmen Sie die Bedeutung des Satzes.
::exercise
Was drückt „Ich hätte gern mehr Zeit“ aus?

Tatsache / Realität
*Wunsch
Vergangenheit
BACK:
Мне хотелось бы иметь больше времени.
CONTEXT:
„Habe“ обозначает факт; „hätte gern“ выражает желание, а не прошедшее время.
::level
B1
::topic
Konjunktiv II · Gegenwart
```

Порядок слов — Trainer Choice:

```text
FRONT:
::task
Wählen Sie die richtige Wortstellung.
::exercise
Wenn ich mehr Zeit hätte, {ich würde|*würde ich} mehr lesen.
BACK:
Если бы у меня было больше времени, я бы больше читал.
CONTEXT:
После начального придаточного главный глагол занимает вторую позицию, перед подлежащим.
::level
B1
::topic
Konjunktiv II · Gegenwart
```

Формы — Match:

```text
FRONT:
::task
Ordnen Sie die Pronomen den Formen zu.
::exercise
@match
ich => würde
du => würdest
er/sie/es => würde
wir => würden
ihr => würdet
sie/Sie => würden
BACK:
Формы werden в Konjunktiv II.
CONTEXT:
В 1-м и 3-м лице единственного числа форма одинакова: würde.
::level
B1
::topic
Konjunktiv II · Gegenwart
```
