# Чек-лист проверки перед выдачей (Validation)

Перед формированием финального ответа агент обязан проверить сгенерированный результат по следующему чек-листу:

1. **Базовые блоки (Уровень 1)**:
   - `FRONT:` обязателен; `BACK:` и `CONTEXT:` необязательны.
   - Разделитель `<<<LERNE_CARD>>>` стоит строго МЕЖДУ карточками (не в начале и не в конце).
2. **Выбор типа**:
   - Выбран правильный тип упражнения, соответствующий механике исходного задания.
   - По умолчанию сохранена оригинальная механика, ничего не придумано без необходимости.
   - Не потеряна ли часть исходного задания (все ли пункты/предложения перенесены).
3. **Согласованность и грамматика**:
   - `FRONT` и `BACK` согласованы между собой.
   - Все правильные ответы грамматически верны и точны.
4. **Различение маркеров**:
   - `::source` (исходный текст для чтения во `FRONT`) не перепутан с `CONTEXT` (тема/уровень карточки).
   - `::options` (список слов в шапке задания) не перепутан с синтаксическим `@options` (варианты Word Bank).
5. **Trainer Input / Choice / Mixed**:
   - Комбинирование (`{*Als|Wenn}` + `[[hatte]]`) разрешено и оформлено в рамках единого типа `trainer`.
   - Внутри `[[...]]` находится строго один точный ответ, без символа `|` (нет `[[war|ist]]`).
6. **Free Text (@free)**:
   - Маркер `@free` используется ТОЛЬКО для открытых ответов (эссе, мнение, рассказ). Если есть точный ответ — используется `trainer-input`.
   - Для `@free` блок `BACK` не пустой и содержит пример ответа (Musterlösung).
7. **Word Bank**:
   - Использован маркер `@wordbank` (а не `@word_bank`).
   - Все ID пропусков `<<id>>` валидны (только латинские буквы, цифры, `-`, `_`, без пробелов) и уникальны.
   - Каждый `<<id>>` из текста имеет строго одну строку `id=Ответ` в `BACK`, и наоборот.
   - Все ответы из `BACK` присутствуют в `@options`.
8. **Запрещенные теги и псевдо-разметка**:
   - НЕТ `@free_text` (только `@free`).
   - НЕТ `@word_bank` (только `@wordbank`).
   - НЕТ `::answer`.
9. **Чистота финального вывода**:
   - Вывод содержит ТОЛЬКО готовые карточки.
   - Нет Markdown code blocks (\`\`\`text), комментариев, приветствий и нумерации.
   - Карточки однозначно и без ошибок распознаются парсером Lerne.
