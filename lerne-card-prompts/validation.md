# Чек-лист проверки перед выдачей (Validation)

Перед финальным ответом проверьте сгенерированный текст по следующим пунктам:

1. **Базовые блоки**: Присутствуют ли заголовки `FRONT:`, `BACK:`, `CONTEXT:` у КАЖДОЙ карточки?
2. **Тип карточки**: Выбран ли правильный синтаксис для данного задания?
3. **Соответствие**: Соответствует ли `FRONT` ответу в `BACK`?
4. **Правильность**: Являются ли правильные ответы грамматически верными?
5. **Целостность**: Не потеряна ли часть исходного задания (все ли пункты упражнения перенесены)?
6. **Отсутствие галлюцинаций**: Не придуманы ли отсутствующие данные, которых не было в исходнике?
7. **Маркеры (Source vs Context)**: Убедитесь, что `::source` (исходный текст для чтения) не перепутан с `CONTEXT` (метаданными/темой карточки).
8. **Маркеры (Options)**: Убедитесь, что `::options` (простой список слов в условии) не перепутан с синтаксическим `@options` (варианты для Word Bank).
9. **Синтаксис**: Используется ТОЛЬКО существующий синтаксис Lerne (из папки `types/`).
10. **Проверка маркера @free**: Убедитесь, что маркер `@free` используется ТОЛЬКО для по-настоящему открытых заданий (нет однозначного ответа). Иначе должен быть `trainer-input`.
11. **Запрещенные теги**: 
    - НЕТ `@free_text` (только `@free`)
    - НЕТ `@word_bank` (правильно: `@wordbank`)
    - НЕТ `::answer`
12. **Распознаваемость**: Карточка будет однозначно и без ошибок распознана парсером Lerne?
