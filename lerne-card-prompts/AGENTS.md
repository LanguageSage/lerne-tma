# Antigravity: подготовка карточек Lerne

Создавай готовый текст карточек для импорта из методических заготовок, фотографий, теории, обычных текстов и упражнений.

## Выбор механики

Определяй тип по учебной цели и действию ученика, а не по названию в исходнике. Сохраняй смысл и полезную механику готового задания; исправляй неточно указанный тип. Если синтаксиса или механики нет, самостоятельно подбирай её и формулируй необходимое задание в рамках цели пользователя. Не добавляй посторонние задания.

| Действие ученика | Правила типа |
| --- | --- |
| Ввести точное слово, форму или перевод | [Trainer Input](types/trainer-input.md) |
| Выбрать вариант внутри текста | [Trainer Choice](types/trainer-choice.md) |
| Выбрать и ввести в одном задании | Оба файла Trainer; единый тип `trainer` |
| Выбрать ответ из списка под вопросом | [Quiz](types/quiz.md) |
| Сопоставить пары | [Match](types/match.md) |
| Собрать фразу из слов | [Puzzle](types/puzzle.md) |
| Заполнить пропуски из общего банка | [Word Bank](types/word-bank.md) |
| Дать открытый ответ: мнение, рассказ, эссе | [Free Text](types/free-text.md) |
| Исправить готовый текст в поле | [Editable Text](types/editable-text.md) |
| Вспомнить ответ и перевернуть карточку | [Standard](types/standard.md) |
| Прочитать правило или объяснение | [Theory](types/theory.md) |

## Порядок работы

1. Прочитай [common.md](common.md). Выдели отдельные задания и теоретические блоки; одну страницу не своди к одному типу.
2. Прочитай подходящие правила источника: [фото](patterns/image-source.md), [учебник и заготовки](patterns/textbook-exercise.md), [обычный текст](patterns/raw-text.md), [теория](patterns/theory-adaptation.md). Их можно сочетать.
3. Выбери механику для каждого блока и прочитай только нужные `types/*.md`.
4. Создай или обработай карточки, затем проверь их по [validation.md](validation.md). Формат финального вывода задан в common.md.

При редактировании готовых карточек учитывай их назначение; правила сохранения Theory находятся в types/theory.md.
