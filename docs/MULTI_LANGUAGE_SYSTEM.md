# 🌍 Мультиязычная Система и Изоляция Контента

В данном документе описан принцип работы мультиязычной системы **Lerne TMA**, поддерживающей обучение нескольким иностранным языкам.

---

## 🎯 Поддерживаемые Языки

На текущий момент поддерживается 3 целевых языка обучения:
- 🇩🇪 **Deutsch (Немецкий)** — код `de` (артикли der/die/das, падежи, глаголы с предлогами).
- 🇬🇧 **English (Английский)** — код `en` (разговорные фразы, времена, фразовые глаголы).
- 🇳🇴 **Norsk (Норвежский)** — код `no` (Bokmål, роды en/ei/et, базовые фразы).

---

## 🔒 Изоляция Пространств

Система построена по принципу **строгой изоляции языковых пространств**:

```
[ Пользователь переключает язык на English (en) ]
                       │
                       ▼
 ┌─────────────────────────────────────────────────────────┐
 │ 1. Колоды: Показываются ТОЛЬКО колоды target_language='en'│
 │ 2. Папки: Показываются ТОЛЬКО папки target_language='en'  │
 │ 3. Промпты ИИ: Используются промпты для English         │
 └─────────────────────────────────────────────────────────┘
```

---

## 🗄 Реализация в базе данных

### 1. Колоды (`tma_deck`) и Папки (`tma_folder`)
- Поле `target_language` в таблицах `tma_deck` и `tma_folder`.
- Сервисный метод `get_active_decks(user_id, target_language)` возвращает только контент, соответствующий выбранному языку.
- При изменении активного языка во фронтенде происходит автоматический повторный запрос к бэкенду для обновления сетки колод.

### 2. Промпты ИИ (`tma_custom_prompt`)
- Каждая языковая пара имеет свои собственные ИИ-промпты для генерации примеров, перевода и контекста.
- Поле `target_language` гарантирует, что для немецких карточек применяются промпты немецкого языка, а для английских — английского.

---

## 📱 Пользовательский Опыт (UX) Выбора Языка

1. **Первый вход**: Пользователю показывается модальное окно выбора языка.
2. **Переключение**: Переключатель языков доступен в верхней части главного экрана.
3. **Сохранение**: Выбранный язык сразу синхронизируется с облаком Telegram и Supabase PostgreSQL DB, исключая повторные запросы.
