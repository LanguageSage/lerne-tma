# Тестовые данные

Тестовый код остаётся в `app/src/**/__tests__/`, `api/tests/`, `scripts/tests/`, `tests/` и `tools/`. Все fixtures, снимки уроков, результаты проверок и другие данные тестов размещайте только в `local/test-data/`. Для порядка используйте подпапки `fixtures/`, `browser/`, `lesson-qa/`, `examples/`, `audio/` и `reports/`.

`local/test-data/` исключён из Git и деплоя. Не сохраняйте реальные тексты карточек, ID карточек и выгрузки курсов в отслеживаемых файлах. Источник учебных материалов — БД; локальные снимки нужны только для ручной диагностики и не публикуются.

Тесты, которые должны запускаться после чистого клонирования или в CI, создают небольшие вымышленные данные в самом тесте. Проверки на локальных снимках требуют предварительно подготовленного `local/test-data/`; отсутствие этих данных означает, что такую проверку выполнить нельзя. Не подменяйте отсутствующий снимок пустым файлом и не считайте пропущенную проверку успешной.

Существующие локальные данные этого рабочего места перенесены в `local/test-data/fixtures/`, `local/test-data/browser/fixtures/`, `local/test-data/lesson-qa/` и `local/test-data/examples/structured_cards_v2/`. Скрипты и тесты используют эти пути.
