# Тестовые данные

Тестовый код остаётся в `app/src/**/__tests__/`, `api/tests/`, `scripts/tests/`, `tests/` и `tools/`.

Для автоматических проверок после чистого клонирования используйте вымышленные данные непосредственно в тестах или отслеживаемые `tests/fixtures/`. Здесь нельзя хранить реальные пользовательские записи, тексты/ID из выгрузок уроков, токены, конфигурацию подключения, локальные БД и резервные копии.

`tests/fixtures/` содержит:

- `exercise_detection_corpus.json`: 83 синтетических сценария с прежними ожидаемыми Python/JS классификациями и явно отмеченными расхождениями. Синтаксис сохранён, естественный текст заменён вымышленными токенами, ID заменены последовательными тестовыми номерами.
- `quiz_boundaries.json`, `quiz_compact_labels.json`: нумерованное условие, отдельный блок вариантов, компактные метки и неоднозначные границы.
- `structured_cards_v2/`: пять рукописных примеров JSON V2 со строковыми ID; все восемь типов, смешанный trainer, дубликаты match/puzzle/word bank, политики free text. Это примеры контракта, а не экспорт пользовательских записей.
- `editable-cards.json`: все 65 синтаксических форм с вымышленными токенами для исправления, навигации и reset.
- `lesson-qa/`: `card-cases.json` сохраняет все 678 исходных синтаксических сценариев с заменой текста и ID; генератор создаёт синтетические исходный и исправленный уроки, список исходных ID и шесть предложений паспортов. Сохраняются размеры 14 колод / 678 карточек, экзамен 46+2, ошибочный/исправленный ключ Quiz, отклонение неавторских вариантов, source/task, поддержка ответа и стабильность ID/порядка.

Генератор уроков не читает локальные снимки, БД или приложение:

```sh
python tests/fixtures/generate_lessons.py
python tests/fixtures/generate_lessons.py --check
npm run check
```

JSON уже включён в Git; генерация не является обязательным шагом перед тестами. Обычный clone содержит историю, необходимую для проверки provenance card-core. После shallow clone выполните `git fetch --unshallow`; CI использует `actions/checkout` с `fetch-depth: 0`. `.gitattributes` сохраняет LF в card-core, поскольку проверяются исходные байты, а не нормализованный текст.

`local/test-data/` остаётся исключённым из Git каталогом для приватных снимков, ручной диагностики, временных файлов и результатов проверок. Тесты могут создавать здесь новые SQLite-файлы, аудио, wheel и отчёты; заранее подготовленные файлы отсюда для автоматических тестов не требуются. Отдельные ручные инструменты `prepare_relativsaetze_updates.py` и `lesson_qa.py --snapshot ...` по-прежнему работают с явно подготовленными приватными снимками. Они не входят в CI.

Не публикуйте `local/test-data/` и не подменяйте отсутствующий реальный снимок пустым файлом. Автоматические синтетические проверки не заменяют аудит реального учебного материала.

Корневой allowlist `.vercelignore` и явное правило `tests/` исключают фикстуры и генератор из Vercel upload. Тестовые `__tests__` также исключены. `python scripts/verify_deploy_files.py` проверяет все текущие фикстуры и будущий путь-маркер; `test_deploy_manifest.py` закрепляет эту границу без деплоя.
