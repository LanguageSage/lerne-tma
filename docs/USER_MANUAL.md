## 1. Введение и Архитектура системы

### 1.1 Концепция приложения
**Lerne** — это интеллектуальная платформа для изучения иностранных языков и терминологии, сочетающая научно доказанный метод интервальных повторений (**Spaced Repetition System — SRS**) с возможностями современных генеративных нейросетей (ИИ-перевод, контекст, озвучка носителями языка, иллюстрации) и геймифицированными тренажерами.

Приложение спроектировано для максимальной скорости обучения: от мгновенного создания карточки в 1 клик через ИИ до фонового прослушивания («Автопилот») во время прогулок, тренировок или поездок.

### 1.2 Технологический стек
- **Frontend**:
  - React 19, Vite.
  - Управление состоянием: **Zustand** (разделенные независимые хранилища `useUiStore`, `useDeckStore`, `useSessionStore`, `useSettingsStore`, `useCollaborativeStore`, `useLanguageStore`).
  - Локальная база данных: **Dexie.js** (IndexedDB обертка с транзакционной целостностью).
  - Анимации: **Framer Motion** (3D флипы карточек, модальные переходы, drag-and-drop).
  - Иконки и UI: **Lucide React**, Glassmorphism CSS, кастомные динамические темы.
- **Backend (`/api`)**:
  - **FastAPI** (Python 3.10+).
  - ORM: **Peewee** с поддержкой SQLite (`lerne.db`, `tma.db`) и Supabase PostgreSQL.
  - Голосовой движок: **edge-tts** (прямой синтез речи через нативные нейронные голоса Microsoft Edge Neural TTS).
  - Интеграция ИИ: Мультипровайдерный адаптер (OpenAI, Google Gemini, DeepSeek, Groq, Anthropic Claude, OpenRouter).
  - Telegram Bot: `python-telegram-bot` для авторизации, уведомлений и deep link ссылок.

### 1.3 Оффлайн-первый подход (Offline-First)
Архитектура Lerne построена по принципу **Local-First / Offline-First**:
1. **Все данные сохраняются локально в IndexedDB** мгновенно. Пользователь может создавать колоды, учить слова, проходить тренажеры в самолете или метро без подключения к сети.
2. **Очередь синхронизации (Sync Queue)**: Все изменения (создание, оценка карточки, удаление) логируются в локальный журнал изменений.
3. **Фоновая синхронизация**: При появлении интернета фоновый воркер синхронизирует состояние с сервером Supabase PostgreSQL по таймстемпам `updated_at`, автоматически разрешая возможные конфликты.

### 1.4 Кроссплатформенность
Приложение адаптировано под 3 ключевые среды исполнения:
- **Telegram Mini App (TMA)**:
  - Интеграция с `window.Telegram.WebApp`.
  - Использование нативной кнопки «Назад» Telegram для навигации по модальным окнам и экранам.
  - Виброотклик (**Haptic Feedback**) при перевороте карточек, оценках и нажатиях.
  - Подтверждение закрытия (`enableClosingConfirmation`), предотвращающее случайный свайп окна вниз во время учебы.
- **Веб-браузер / PWA**:
  - Полнофункциональная веб-версия с поддержкой горячих клавиш клавиатуры (Space, 1-4, стрелки) и адаптивной версткой для Desktop/Tablet/Mobile.
- **Android (Capacitor)**:
  - Нативная сборка в APK с аппаратным ускорением, кэшированием аудио в память устройства и перехватом аппаратной кнопки «Назад».

## 2. Языковая модель и Начало работы

### 2.1 Двухуровневая языковая система
Lerne использует разделение языкового окружения на два независимых слоя:
1. **Язык интерфейса и объяснений (Native Language)**: Язык, на котором отображаются меню, кнопки, справка, а также язык, на который ИИ переводит слова и объясняет грамматические нюансы (по умолчанию: Русский `ru`, также поддерживаются Украинский `uk`, Английский `en`, Немецкий `de`, Испанский `es` и др.).
2. **Изучаемый язык (Target Language)**: Язык слов в колоде (например, Английский `en`, Немецкий `de`, Испанский `es`, Французский `fr`, Итальянский `it`, Польский `pl`, Японский `ja`, Китайский `zh` и др.).

### 2.2 Первый запуск и выбор языков
При первом открытии приложения пользователя встречает окно приветствия (`LanguageWelcomeModal`):
1. Выбор родного языка (автоматически сохраняется в хранилище и локализует весь UI).
2. Выбор первого изучаемого языка.
3. Интерактивный тур (`TutorialOverlay`), подсвечивающий ключевые кнопки и объясняющий базовый цикл: *Колода → Карточка → Переворот → Оценка*.

## 3. Главный экран: Колоды и Папки (`DeckGrid`)

Главный экран — это командный центр пользователя. Здесь собраны все наборы слов, каталогизированные по папкам и изучаемым языкам.

```
+---------------------------------------------------------------+
|  🌐 [RU]  |  🇬🇧 [EN]       [ 🔍 Поиск по словам... ]   (⚙️) (?) |
+---------------------------------------------------------------+
|  📁 Папки: [ Все ] [ Учеба ] [ Путешествия ] [ + Папка ]       |
+---------------------------------------------------------------+
|  +---------------------------+  +---------------------------+  |
|  | 🇬🇧 Английский A2-B1       |  | 🇩🇪 Немецкий: Работа       |  |
|  | 45 карточек (🔥 12 Due)   |  | 120 карточек (🔥 0 Due)   |  |
|  | [======     ] 65% SRS     |  | [==========] 100% SRS     |  |
|  | [▶ Учить] [⚡ Тренажер]   |  | [▶ Учить] [⚡ Тренажер]   |  |
|  | [🗂 Карточки] [ ⋯ Меню ]   |  | [🗂 Карточки] [ ⋯ Меню ]   |  |
|  +---------------------------+  +---------------------------+  |
+---------------------------------------------------------------+
|  [ + Создать колоду  |  ▼ Пакетное / Импорт / Дубли / Корзина ] |
+---------------------------------------------------------------+
```

### 3.1 Верхняя панель управления (`DeckGridHeader`)
- **Селектор родного языка (`NativeLanguageSelectorBadge`)**: Позволяет на лету сменить язык интерфейса.
- **Селектор изучаемого языка (`LanguageSelectorBadge`)**: Фильтрует отображаемые колоды по выбранному целевому языку (или показывает все языки).
- **Поисковая строка (`SearchBar`)**: Мгновенный «живой» поиск. Ищет совпадения не только по названиям колод, но и по всем словам, переводам и контекстным примерам внутри них.
- **Кнопка настроек (`SettingsModal`)**: Открывает полноценный центр управления (дизайн, ИИ, голоса, профиль).
- **Кнопка справки (`?`)**: Запускает контекстный интерактивный гид или открывает справочный экран.
- **Профиль / Гостевой баннер (`GuestBanner` / `UserBadge`)**: Отображает статус авторизации, аватар пользователя и ID.

### 3.2 Дерево папок и навигация (`FolderTreeNav`)
Папки позволяют структурировать десятки колод по категориям (например: *«Работа»*, *«Экзамен IELTS»*, *«Грамматика»*, *«Сленг»*):
- **Создание папки**: Кнопка `+ Папка` открывает ввод названия и выбор цветового маркера.
- **Перемещение колоды в папку**: Через контекстное меню карточки колоды (`⋯` → *«Переместить в папку»*).
- **Управление папкой**: Долгое нажатие или кнопка шестеренки на вкладке папки позволяет переименовать ее, изменить порядок или удалить.
- **Удаление папки**: При удалении папки колоды **не удаляются**, а безопасно перемещаются в корневой каталог («Все колоды»).

### 3.3 Карточка колоды (`DeckCardItem`) и индикаторы SRS
Каждая колода представлена интерактивным блоком:
- **Обложка / Флаг**: Флаг языка или кастомное изображение/градиент.
- **Название колоды** и бейдж изучаемого языка.
- **Счетчики карточек**:
  - Общее количество карточек.
  - Бейдж **🔥 К повторению (Due)**: Показывает, сколько карточек требуют повторения прямо сейчас по алгоритму интервальных повторений. Если счетчик красный — пора повторить слова для закрепления в долговременной памяти.
- **Прогресс-бар SRS**: Цветовая шкала соотношения карточек в колоде:
  - 🟦 *Новые (New)* — еще не открывались.
  - 🟧 *На изучении (Learning)* — находятся в активной фазе повторений.
  - 🟩 *Выученные (Mastered)* — интервал повторения превысил 21 день.
- **Бейджи совместной работы**: Иконка пользователей, если колода расшарена для совместного изучения с друзьями или учениками.

### 3.4 Меню быстрых действий колоды
- **Кнопка «Учить» (▶)**: Мгновенный запуск сессии интервального повторения карточек (`StudyView`).
- **Кнопка «Тренажеры» (⚡)**: Открытие меню интерактивных игровых режимов (Quiz, Puzzle, Speech и др.).
- **Кнопка «Карточки» (🗂)**: Переход к полному списку всех слов колоды с возможностью поиска и редактирования.
- **Контекстное меню (`⋯`)**:
  - ✏️ **Переименовать**: Изменение названия и описания (`RenameDeckModal`).
  - 🎨 **Медиа колоды**: Настройка обложки, цвета градиента и иконки (`DeckMediaModal`).
  - 📤 **Поделиться**: Генерация персональной ссылки или ссылки для Telegram.
  - 👥 **Соавторы / Синхронизация**: Настройка прав доступа и совместного редактирования (`CollaboratorsModal`).
  - 💾 **Экспорт**: Выгрузка колоды в файлы формата JSON, CSV или TXT.
  - 📁 **Переместить в папку**: Смена родительской папки.
  - 🗑 **Удалить**: Перемещение колоды в Корзину (`TrashManager`) с возможностью восстановления.

### 3.5 Нижняя сплит-кнопка добавления (`SplitButton`)
Основная плавающая кнопка внизу экрана:
- **Главная часть**: `+ Создать колоду` — быстрое создание чистого набора.
- **Выпадающее меню (стрелка)**:
  - 🪄 **ИИ-генератор колоды**: Создание полной колоды по теме за 5 секунд.
  - 📥 **Импорт**: Загрузка из Anki, Quizlet, CSV, TSV.
  - ⚡ **Пакетное добавление**: Быстрый построчный ввод слов.
  - 🔍 **Поиск дубликатов**: Сканирование одинаковых слов.
  - 🗑 **Корзина**: Просмотр и восстановление удаленных колод/слов.

## 4. Управление словами в колоде (`CardList`)

Экран списка карточек предназначен для полного аудита, поиска, массового редактирования и тонкой настройки карточек внутри выбранной колоды.

```
+---------------------------------------------------------------+
|  ← Назад   |  Колода: Английский B2 (45 слов)          (🔍) (+) |
+---------------------------------------------------------------+
|  [ Все: 45 ] [ Новые: 10 ] [ В учебе: 20 ] [ Выучено: 15 ]     |
|  [ 🔥 Требуют повторения: 8 ]                                 |
+---------------------------------------------------------------+
|  [ ✓ Выбрать все ]                                             |
|                                                               |
|  +---------------------------------------------------------+  |
|  | 🔊 resilient [rɪˈzɪl.jənt]                     [ B2 ]   |  |
|  | ➔ устойчивый, жизнерадостный, упругий                   |  |
|  | 💬 He is resilient in the face of difficulties.         |  |
|  | 📅 Повтор: через 4 дня (SM-2: Ease 2.50)         [ ⋯ ]  |  |
|  +---------------------------------------------------------+  |
|  +---------------------------------------------------------+  |
|  | 🔊 ubiquitous [juːˈbɪk.wɪ.təs]                 [ C1 ]   |  |
|  | ➔ вездесущий, повсеместный                              |  |
|  | 💬 Smartphones have become ubiquitous.                  |  |
|  | 📅 Новый (еще не изучался)                       [ ⋯ ]  |  |
|  +---------------------------------------------------------+  |
+---------------------------------------------------------------+
|  [ + Добавить карточку ]                                      |
+---------------------------------------------------------------+
```

### 4.1 Фильтры по статусам обучения
В верхней части списка расположены интерактивные фильтры-чипсы:
- **Все**: Полный список слов колоды.
- **Новые (New)**: Слова, которые пользователь еще ни разу не учил.
- **В учебе (Learning)**: Слова с активным графиком повторений (интервал от 10 минут до 20 дней).
- **Выученные (Mastered)**: Слова, прочно усвоенные памятью (интервал повторения более 21 дня).
- **Требуют повторения (Due)**: Карточки, чей срок очередного повторения наступил.

### 4.2 Поиск и быстрый предпросмотр аудио
- Строка поиска мгновенно фильтрует карточки по совпадению в слове, транскрипции, переводе или предложении-примере.
- Иконка динамика `🔊` на каждой карточке позволяет мгновенно воспроизвести нативное произношение слова без входа в режим урока.

### 4.3 Меню действий карточки (`CardActionModal`)
По нажатию на кнопку `⋯` на любой карточке открывается меню управления:
- ✏️ **Редактировать**: Открывает полный редактор карточки (`CardEditor`).
- 🔄 **Сбросить прогресс SRS**: Сбрасывает историю ответов и интервалы, переводя карточку в статус «Новая».
- ⏸ **Приостановить / Возобновить (Toggle Suspend)**: Исключает слово из тренировок без его удаления (удобно для слов, которые пока не нужны).
- 📦 **Переместить в другую колоду**: Переносит карточку в выбранную колоду с сохранением всей истории SRS.
- 📋 **Скопировать в другую колоду**: Создает дубликат карточки в другой колоде.
- 🔗 **Поделиться карточкой**: Экспорт карточки в виде текста или красивой картинки-цитаты.
- 🗑 **Удалить**: Перемещение карточки в корзину.

### 4.4 Пакетный режим выделения (Batch Selection)
При включении чекбокса выбора карточек активируется панель групповых операций:
- Выбор нескольких или всех карточек одним нажатием.
- **Групповое удаление**: Быстрая очистка устаревших слов.
- **Групповое перемещение**: Перенос пачки слов в другую колоду.
- **Групповой сброс SRS**: Сброс прогресса для выбранной группы.
- **Групповой экспорт**: Выгрузка выделенных слов в CSV/TXT.

## 5. Создание и редактирование карточек (`CardCreator` / `CardEditor`)

Форма карточки спроектирована для максимальной информативности и удобства как ручного ввода, так и полностью автоматической генерации через нейросети.

```
+---------------------------------------------------------------+
|  ← Отмена         Новая карточка                [ Сохранить ] |
+---------------------------------------------------------------+
|  Лицевая сторона (Front):                                     |
|  [ Слово или фраза: e.g. serendipity                        ] |
|  [ ✨ Заполнить с помощью ИИ (Magic Fill)                   ] |
|                                                               |
|  [ Транскрипция: [ˌser.ənˈdɪp.ə.ti] ]  [ Уровень: (B2 ▼) ]    |
|  [ Часть речи: (существительное ▼)  ]                         |
|                                                               |
|  Контекстный пример:                                          |
|  [ Finding this book was pure serendipity.                  ] |
|                                                               |
|  Озвучка:                                                     |
|  [ 🔊 Сгенерировать Edge-TTS ] [ 🎙 Запись ] [ 📁 Файл ]      |
+---------------------------------------------------------------+
|  Обратная сторона (Back):                                     |
|  [ Перевод: счастливая случайность, интуитивная прозорливость] |
|  [ Перевод контекста: Находка этой книги была чистой ...    ] |
|  [ Грамматика / Заметки: от персидской сказки 'Три принца... ] |
|                                                               |
|  Иллюстрация:                                                 |
|  [ 🖼 ИИ-генерация ] [ 🔍 Unsplash ] [ 📷 Загрузить ]         |
|  +-----------------------------+                              |
|  | [ Картинка ]  [ ✂ Обрезать ] |                              |
|  +-----------------------------+                              |
+---------------------------------------------------------------+
```

### 5.1 Анатомия карточки
Каждая карточка Lerne содержит богатый набор метаданных:
- **Лицевая сторона (Front)**:
  - *Целевое слово / идиома / фразовый глагол*.
  - *Фонетическая транскрипция (IPA / Pinyin / ромадзи)*.
  - *Часть речи (существительное, глагол, прилагательное, наречие, фраза)*.
  - *Уровень сложности по шкале CEFR (A1, A2, B1, B2, C1, C2)*.
  - *Контекстный пример*: Живое предложение на изучаемом языке, демонстрирующее грамматическое окружение и предлоги.
  - *Аудиофайл произношения*.
- **Обратная сторона (Back)**:
  - *Основной перевод* на родной язык.
  - *Дополнительные варианты перевода и синонимы*.
  - *Перевод контекстного примера*.
  - *Грамматический комментарий / Мнемоника / Ассоциация*.
  - *Иллюстрация*: Изображение, закрепляющее зрительный образ слова.

### 5.2 Магия ИИ ("Помощь ИИ" / Magic Fill)
Самый мощный инструмент создания контента:
1. Вы вводите только слово (например, *«ephemeral»*).
2. Нажимаете кнопку **«✨ Заполнить с помощью ИИ»**.
3. Нейросеть за доли секунды:
   - Определяет часть речи и уровень сложности (C1).
   - Генерирует точную международную транскрипцию `[ɪˈfem.ər.əl]`.
   - Подбирает точный и естественный перевод (*«эфемерный, недолговечный, преходящий»*).
   - Составляет образцовый контекстный пример (*«Fame in the internet age is often ephemeral.»*).
   - Переводит пример на родной язык.
   - Добавляет полезный этимологический или грамматический комментарий.
   - Автоматически инициирует синтез высококачественной озвучки нативным голосом Edge-TTS.

### 5.3 Синтез речи и запись голоса
Lerne поддерживает 3 способа прикрепления аудио к карточке:
- **Нейронный синтез Edge-TTS**: Одно нажатие генерирует кристально чистую озвучку от носителя языка с естественными интонациями и паузами.
- **Запись с микрофона (`🎙`)**: Позволяет преподавателю или студенту записать собственный голос прямо в браузере/приложении.
- **Загрузка аудиофайла (`📁`)**: Поддержка форматов MP3, WAV, AAC, OGG.

### 5.4 Работа с изображениями и встроенный редактор (`ImageEditorModal`)
Визуальные ассоциации ускоряют запоминание слов на 40%:
- **ИИ-генерация картинок**: Нейросеть (DALL-E / Gemini) рисует уникальную ассоциативную иллюстрацию под конкретный контекст слова.
- **Поиск по Unsplash**: Быстрый подбор профессиональных фотографий из бесплатной библиотеки.
- **Загрузка из галереи / Камера**: Прямая загрузка с телефона или ПК.
- **Встроенный редактор изображений (`ImageEditorModal`)**:
  - Кадрирование под соотношение сторон (1:1 квадрат, 4:3, 16:9).
  - Поворот изображения на 90° / 180°.
  - Зум и перемещение фокуса.
  - Настройка яркости и контрастности.

## 6. Режим интервального обучения SRS (`StudyView`)

Режим интервальных повторений — это ядро методологии Lerne. Он устраняет необходимость в бесполезной зубрежке, показывая слово ровно в тот момент, когда человеческий мозг готов его забыть (кривая Эббингауза).

```
+---------------------------------------------------------------+
|  ← Колоды   [======        ] 12/45   (🔥 8) (📊) (✏️) (+) (⚙️) |
+---------------------------------------------------------------+
|                                                               |
|  +---------------------------------------------------------+  |
|  |                                                         |  |
|  |                     ubiquitous                          |  |
|  |                  [juːˈbɪk.wɪ.təs]                       |  |
|  |                                                         |  |
|  |                 [ 🔊 Прослушать ]                       |  |
|  |                                                         |  |
|  |     💬 Smartphones have become ubiquitous in daily life.|  |
|  |                                                         |  |
|  |           ( 🔄 Нажмите, чтобы увидеть ответ )           |  |
|  +---------------------------------------------------------+  |
|                                                               |
+---------------------------------------------------------------+
|  ПОСЛЕ ПЕРЕВОРОТА:                                            |
|  +---------------------------------------------------------+  |
|  | ➔ вездесущий, повсеместно встречающийся                 |  |
|  | 💬 Смартфоны стали повсеместными в повседневной жизни.   |  |

|  +------------+  +------------+  +------------+  +----------+ |
```

### 6.1 3D-переворот и структура сторон
- **Лицевая сторона**: Пользователь видит иностранное слово, транскрипцию и контекст, слышит произношение и пытается активировать воспоминание в памяти.
- **Переворот (3D Flip)**: Плавная трехмерная анимация переворота по тапу на карточку (или по клавише `Пробел`).
- **Оборотная сторона**: Открывается перевод, перевод примера, мнемоническая подсказка и иллюстрация. Текст примера подсвечивается синхронно со звуком.

### 6.2 Алгоритм SM-2: Градация оценок и расчет интервалов
Алгоритм SuperMemo-2 (SM-2) динамически адаптирует интервал повторения для каждого отдельного слова на основе 4 кнопок оценки:

1. **🔴 Снова (Again / Оценка 1)**:
   - *Значение*: Слово забыто полностью или допущена грубая ошибка.
   - *Результат*: Сброс счетчика повторений (`repetition = 0`), интервал сбрасывается на 10 минут (слово вернется в текущей сессии), фактор легкости (`Ease Factor`) снижается.
2. **🟠 Трудно (Hard / Оценка 2)**:
   - *Значение*: Слово вспомнилось с большим трудом и задержкой.
   - *Результат*: Минимальный шаг интервала (обычно 1 день), `Ease Factor` немного снижается.
3. **🟢 Хорошо (Good / Оценка 3)**:
   - *Значение*: Слово вспомнилось уверенно после небольшой паузы.
   - *Результат*: Стандартный расчет интервала: \( I_n = I_{n-1} \times EF \) (например: 1 день → 3 дня → 8 дней → 21 день).
4. **🔵 Легко (Easy / Оценка 4)**:
   - *Значение*: Слово мгновенно всплыло в памяти без малейших усилий.
   - *Результат*: Увеличенный интервал с бонусным коэффициентом (например: сразу 4 дня → 12 дней → 35 дней), `Ease Factor` повышается.

> **Умные бейджи на кнопках:** Над каждой кнопкой оценки в реальном времени рассчитывается и отображается точная дата следующего появления карточки (`10 мин`, `1 дн`, `4 дн`, `2 нед`, `1 мес`).

### 6.3 Караоке-подсветка текста (`KaraokeText`)
При озвучивании предложения-примера слова подсвечиваются мягким золотым цветом синхронно со звучанием диктора. Это развивает навык аудирования и помогает уху вычленять отдельные слова в слитном потоке иностранной речи.

### 6.4 Режим «Автопилот» (AutoPlay & AutoShow)
Разработан для эффективного обучения в ситуациях, когда руки заняты:
- **Авто-звук**: Карточка автоматически озвучивается сразу при появлении.
- **Пауза на размышление**: Настраиваемая пауза (например, 4 секунды), чтобы пользователь успел вспомнить перевод.
- **Авто-показ**: Карточка сама плавно переворачивается, открывая ответ.
- **Озвучка ответа**: Автоматически воспроизводится перевод и пример.
- **Пауза на оборотной стороне**: Настраиваемая пауза (например, 2 секунды) для закрепления.
- **Авто-переход**: Приложение автоматически ставит оценку «Хорошо» и переходит к следующей карточке.
- **Цикл и повторы**: Возможность зациклить колоду по кругу и задать повторение каждой карточки по 2-3 раза подряд.

### 6.5 Статистика сессии (`SrsStatsModal` и `StudyFinished`)
- **Окно статистики колоды (`SrsStatsModal`)**:
  - График распределения повторений на ближайшие 7–30 дней.
  - Процент запоминания (Retention Rate).
  - Средний коэффициент легкости (Average Ease Factor).
- **Экран завершения (`StudyFinished`)**:
  - Салют из конфетти (`ConfettiBurst`).
  - Количество пройденных карточек, время сессии, точность ответов.
  - Кнопка *«Повторить трудные слова»* для закрепления карточек с оценками *Снова* и *Трудно*.

## 7. Интерактивные тренажеры (`TrainerView`)

Тренажеры дополняют классические карточки, тренируя различные аспекты владения языком: пассивное узнавание, активное воспроизведение, правописание и устную речь.

```
+---------------------------------------------------------------+
|  ← Колоды   Тренажер: Английский B2      Счет: 450 XP  (🔥 Стрик: 7) |
+---------------------------------------------------------------+
|  Режим: [ 🧩 Викторина ] [ 🔤 Пазл ] [ 🎙 Речь ] [ ⚡ Спринт ]  |
+---------------------------------------------------------------+
|                                                               |
|  Выберите правильный перевод для:                             |
|                                                               |
|                        meticulous                             |
|                     [məˈtɪk.jə.ləs]                           |
|                                                               |
|  +---------------------------+  +---------------------------+  |
|  | A) поверхностный, беглый  |  | B) дотошный, тщательный ✓ |  |
|  +---------------------------+  +---------------------------+  |
|  +---------------------------+  +---------------------------+  |
|  | C) вспыльчивый, резкий    |  | D) щедрый, великодушный   |  |
|  +---------------------------+  +---------------------------+  |
|                                                               |
+---------------------------------------------------------------+
```

### 7.1 Викторина (Quiz Mode - `StudyCardQuiz`)
- Классический множественный выбор: дается иностранное слово и 4 варианта перевода на родной язык.
- **Умные дистракторы**: Варианты ответов подбираются из похожих по части речи и уровню слов той же колоды или генерируются нейросетью, исключая тривиальные подсказки.
- Мгновенная цветовая индикация (зеленый/красный) с виброоткликом.

### 7.2 Конструктор фраз / Пазл (Puzzle Mode - `StudyCardPuzzle`)
- Тренирует порядок слов и синтаксис.
- Перевод предложения показывается вверху, а слова или слоги иностранной фразы перемешиваются в виде интерактивных плашек внизу.
- Пользователь нажимает на плашки в правильном грамматическом порядке.

### 7.3 Речевой тренажер и произношение (Speech Mode - `StudyCardSpeech`)
- Развивает уверенность в устной речи и убирает языковой барьер.
- Приложение выводит слово или фразу и проигрывает эталонное звучание.
- Пользователь нажимает на иконку микрофона и произносит текст.
- Встроенный аудио-анализатор распознает речь и рассчитывает **процент совпадения произношения (Similarity Match %)**.
- Если результат выше заданного порога (по умолчанию 75%) — задание засчитывается.

### 7.4 Скоростной спринт (Speed Trainer - `StudyCardTrainer`)
- Тренажер на скорость реакции (3–5 секунд на карточку).
- Идеален для доведения узнавания слов до автоматизма перед экзаменами или поездками.

### 7.5 Контекстные пропуски (Cloze Deletion)
- Показывается предложение-пример, в котором целевое слово скрыто маской: *«The scientist made a _______ discovery.»*
- Задача: выбрать правильную грамматическую форму слова из предложенных вариантов.

### 7.6 Реверс-режим (Reverse Mode)
- Тренирует активный словарный запас (перевод с родного языка на иностранный).
- На экране отображается русский перевод, необходимо вспомнить и ввести или выбрать иностранное слово.

### 7.7 Случайный микс (Random Mix Mode)
- Динамически чередует все включенные типы заданий (Викторина → Пазл → Произношение → Пропуски).
- Постоянная смена когнитивной нагрузки предотвращает усталость и обеспечивает максимальную пластичность нейронных связей.

## 8. Импорт, экспорт и пакетная генерация

Lerne позволяет легко переносить свои учебные материалы из любых существующих приложений или генерировать их с нуля за считанные секунды.

### 8.1 Импорт файлов (`ImportModal`)
Поддерживаются следующие форматы:
- **CSV / TSV**: Табличные файлы с возможностью сопоставления колонок (Front, Back, Context, Transcription, Tags).
- **Anki (.apkg / Anki Text)**: Полный импорт колод из популярной программы Anki с сохранением переводов и примеров.
- **Quizlet**: Прямая вставка скопированного текста из Quizlet (с разделителями Tab или запятыми).
- **Простой текст**: Вставка любого списка строк формата `Слово - Перевод` или `Слово | Перевод | Пример`.

### 8.2 ИИ-генератор колод по теме и уровню
Уникальная функция создания персонализированных учебных курсов:
1. Вы вводите тему: например, *«Собеседование на позицию Python Developer»*, *«Визит к врачу в Испании»*, *«Фразовые глаголы для путешествий»*.
2. Выбираете уровень (A1, A2, B1, B2, C1, C2) и количество карточек (10, 20, 30, 50).
3. ИИ генерирует готовую колоду с актуальной лексикой, естественными контекстами, переводами и автоматической озвучкой.

### 8.3 Пакетный ввод слов (`BatchCardModal`)
Быстрое добавление десятков слов без заполнения индивидуальных форм. Просто вставьте список слов в текстовое поле — приложение распарсит их и создаст карточки.

### 8.4 Резервное копирование и экспорт в JSON
- **Полный бэкап базы данных**: Вкладка *«Профиль»* → *«Экспорт резервной копии»*. Создает файл `.json`, содержащий абсолютно все колоды, папки, карточки, настройки дизайна и полную историю повторений SRS.
- **Восстановление из бэкапа**: Импорт JSON-файла восстанавливает данные на любом новом устройстве за 1 секунду.

## 9. Специальные менеджеры и утилиты

### 9.1 Менеджер дубликатов (`DuplicateManager`)
Предотвращает засорение базы одинаковыми словами:
- Автоматическое сканирование всей библиотеки карточек.
- Умный поиск дубликатов с нормализацией регистра (*Apple* vs *apple*), пунктуации и пробелов.
- Варианты объединения: слияние истории повторений, удаление лишней копии или объединение контекстных примеров в одну карточку.

### 9.2 Корзина и восстановление данных (`TrashManager`)
Защита от случайных удалений:
- Удаленные колоды и карточки не стираются физически, а перемещаются в Корзину.
- В корзине отображаются дата удаления, исходная папка и количество слов.
- **Восстановление в 1 клик**: Карточка или колода мгновенно возвращается на свое прежнее место с сохранением прогресса.
- **Полная очистка**: Безвозвратное удаление мусора для освобождения локальной памяти.

### 9.3 Медиа колоды (`DeckMediaModal`)
Позволяет персонализировать визуальный стиль колоды:
- Выбор национальной иконки-флага.
- Назначение цветового градиента обложки.
- Загрузка собственной фоновой картинки колоды.

### 9.4 Синхронизация и совместная работа (`CollaboratorsModal`, `SyncModal`)
- **Совместное изучение (Collaborative Decks)**: Создатель колоды может сгенерировать пригласительную ссылку для друзей или учеников.
- **Индикатор присутствия онлайн (`CollaboratorPresenceBar`)**: В реальном времени показывает аватары пользователей, которые прямо сейчас учат или редактируют данную колоду.
- **Синхронизация в облако**: Ручной и автоматический запуск синхронизации с базой данных Supabase.

## 10. Центр настроек приложения (`SettingsModal`)

Центр настроек Lerne разделен на 10 специализированных вкладок, позволяющих настроить абсолютно каждый аспект работы системы.

### 10.1 Общие настройки (`GeneralTab`)
- **Родной язык**: Выбор языка интерфейса и перевода.
- **Авто-звук (Auto-Play Audio)**: Автоматическое воспроизведение голоса при открытии карточки (Вкл / Выкл).
- **Авто-показ ответа (Auto-Show Answer)**: Автоматический переворот карточки по таймеру (Вкл / Выкл).
- **Пауза на лицевой стороне (сек)**: Время ожидания перед авто-переворотом (1–10 сек, по умолчанию 4 сек).
- **Пауза на оборотной стороне (сек)**: Время показа ответа перед переходом к следующей карточке (1–10 сек, по умолчанию 2 сек).
- **Повторы карточки**: Количество циклов воспроизведения одного слова подряд (1, 2, 3 раза).
- **Порог распознавания речи (Speech Match %)**: Процент точности произношения для успешного прохождения голосового тренажера (50%–95%, по умолчанию 75%).
- **Конфигуратор Случайного микса**: Чекбоксы включения/отключения режимов (Викторина, Пазл, Речь, Спринт, Пропуски, Реверс).

### 10.2 Дизайн карточек (`DesignTab`)
Полная кастомизация внешнего вида учебных карточек:
- **Фон лицевой стороны (Front Background)** и **Фон оборота (Back Background)**:
  - *Liquid Emerald (Жидкий изумруд)* — фирменный градиент Lerne 2026.
  - *Dark Obsidian (Темный обсидиан)* — глубокий контрастный черный.
  - *Dark Midnight (Полуночный синий)* — стильный темно-синий неоновый оттенок.
  - *Dark Minimal (Минимализм)* — лаконичный темно-серый стиль.
  - Градиенты: Sunset Glow, Cyberpunk Purple, Deep Ocean.
- **Шрифты**: Выбор из шрифтов мирового класса (*Comfortaa, Inter, Outfit, Montserrat, Roboto, Playfair Display*).
- **Размер шрифта слова и контекста**: Слайдеры масштабирования (от 1.2rem до 2.4rem).
- **Начертание**: Normal, Semi-Bold, Bold (400, 600, 700, 800) и Italic (курсив).
- **Цвет текста**: Палитра быстрых оттенков + ввод любого произвольного HEX-кода.

## 11. FAQ и решение технических проблем

### В: Работает ли приложение полностью без интернета?
**О:** Да! Все колоды, карточки, алгоритмы повторений SRS и тренажеры функционируют оффлайн через IndexedDB. Озвучка слов, сгенерированная ранее, сохраняется в локальном кэше. Интернет требуется только для первичной генерации новых карточек через ИИ и синхронизации между разными устройствами.

### В: Что делать, если не воспроизводится озвучка?
**О:**
1. Проверьте переключатель беззвучного режима (Mute) на телефоне.
2. В Telegram Mini App на iOS убедитесь, что в настройках звука устройства разрешен звук для Telegram.
3. Откройте *Настройки → Озвучка* и нажмите кнопку проверки голоса.

### В: Как перенести все свои колоды на другой телефон или компьютер?
**О:**
1. На старом устройстве откройте *Настройки → Профиль → Экспорт полного бэкапа*. Сохранится файл `.json`.
2. Перешлите этот файл на новое устройство (например, в Избранное Telegram).
3. На новом устройстве откройте *Настройки → Профиль → Импорт бэкапа* и выберите файл. Все колоды и история повторений восстановятся за секунду.

### В: Как работает распознавание речи в голосовом тренажере?
**О:** Приложение использует технологию Web Speech Recognition. Для точной оценки произносите слово четко в микрофон на расстоянии 15–20 см. При необходимости вы можете снизить порог чувствительности в *Настройках → Общие → Порог распознавания речи* (например, до 60–65%).

### В: Безопасно ли вводить свой ключ API от OpenAI / Gemini?
**О:** Абсолютно безопасно. Ваш API-ключ сохраняется исключительно в локальном хранилище вашего браузера (`localStorage` / `IndexedDB`) на вашем устройстве и никогда не передается третьим лицам или на сторонние серверы. Запросы к нейросети отправляются напрямую от вашего имени.
