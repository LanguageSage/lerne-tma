# Состояние миграции Lerne на SQLite

## Выполнено

- **Общая схема.** TMA `fded60ed` и `734c8dc9` содержат канонические SQL-миграции, Python-модуль и Capacitor-драйвер. TMA `399866a1` исправляет временную блокировку при переходе в WAL. Wheel `lerne-sqlite-schema==0.1.1` в Admin проверен против исходников TMA.
- **Установка Admin.** В `d88bd3b` оба общих wheel подключены к bootstrap. Обычная и editable-установка версии `0.1.1` прошли в отдельных окружениях.
- **Рабочие сценарии Admin.** `53483fe` подключает подготовленную каноническую SQLite к LOCAL-запуску Admin. Проверены импорт и его повтор, пакетные AI и TTS с тестовыми провайдерами, публикация и обновление через «Автор», списки, мягкое удаление и экспорт Native V2. Карточки, медиасвязи и квитанции записываются в общей транзакции. В тестах сбоя и повторной записи сохранились прогресс, заметки и ID карточек.
- **Подготовка пустой базы Admin.** `cd8f7ea` добавляет `--init-sqlite NEW_FILE`. Команда применяет общие миграции к новому временному файлу и публикует его по указанному пути без перезаписи. Создание и отказ на существующем пути проверены.

## Текущий этап

Согласован один профиль Admin. При переносе сохраняются каталоги и исходное авторство для обмена. Материалы других владельцев требуют явного сопоставления.

Подключение SQLite включается во внешнем `config/local.json` через `admin_database`. Запуск проверяет подготовленную БД в режиме чтения. Рабочий LOCAL пока использует прежнюю конфигурацию. Новая SQLite принимает только Native V2. Старые 4694 карточки LOCAL исключены из проверки, конвертации и переноса. Исходные базы остаются на месте. [ZIP конвертера с зависимостями и инструкцией](https://drive.google.com/file/d/1r3dhTSENfvadeMB_2BF6zaLnsXcctXQR/view) сохранён в `Lerne_Архив/03_Experiments`. Из TMA удалены конвертер и его команды.

После удаления конвертера прошли 126 целевых тестов TMA. Android Offline начал использовать общий ключ TTS и проверяет SHA-256 файла перед повторным воспроизведением через существующий файловый плагин. Прошли 30 Node-тестов схемы, TTS и архивов. Метаданные TTS пока сохраняются в Dexie. Проверки выполнены на синтетических данных и с подменой нативных плагинов.
