# 📜 История Вех Разработки и Решенных Проблем (Changelog & Milestones)

Хронологический архив основных технических этапов, рефакторинга и крупных обновлений проекта **Lerne TMA**.

---

## 🏆 Ключевые Вехи (Milestones)

### 🔹 Август 2026: Защита от повторного выбора языка в Telegram WebApp
- **Проблема**: При каждом открытии Mini App внутри встроенного браузера Telegram (iOS/Android WebKit) сбрасывался `LocalStorage`, из-за чего пользователю постоянно предлагалось выбрать язык заново.
- **Решение**: 
  - Внедрена поддержка **Telegram CloudStorage API** (`Telegram.WebApp.CloudStorage`).
  - В таблицу `tma_user` PostgreSQL добавлены поля `active_language` и `has_selected_language`.
  - Реализован 3-уровневый каскад восстановления настроек (`LocalStorage` → `CloudStorage` → `Supabase DB`).

### 🔹 Июль 2026: Миграция на PostgreSQL (Supabase Cloud) и Отказоустойчивость
- **Проблема**: Использование локальной БД SQLite вызвало сбои при развертывании в бессерверной среде Vercel (`no such table: tma_folder`).
- **Решение**:
  - Полный перевод проекта на облачный PostgreSQL (Supabase).
  - Настройка гибридного подключения через `psycopg2-binary` и чистый Python-драйвер `pg8000` для предотвращения ошибок скомпилированных C-библиотек.
  - Реализация ленивой инициализации соединений (без зависаний на старте Vercel serverless).

### 🔹 Июль 2026: Изоляция Мультиязычного Контента (DE / EN / NO)
- **Проблема**: Колодки и папки разных языков перемешивались на главном экране при смене языка.
- **Решение**:
  - Введение колонки `target_language` для колод, папок и ИИ-промптов.
  - Разграничение предустановленных колод по уровням (`A2`, `B1`, `B2`).
  - Фильтрация стартовой инициализации `/api/init` строго под выбранный целевой язык.

### 🔹 Июнь 2026: Система Повторений SM-2 и Автономная Синхронизация
- **Внедрение**:
  - Алгоритм интервальных повторений SuperMemo 2 (SM-2) с индивидуальным учетом карточек (`ease_factor`, `interval`, `repetitions`).
  - Поддержка офлайн-режима с фоновой авто-синхронизацией при появлении сети.
  - Модуль дедупликации карточек.
