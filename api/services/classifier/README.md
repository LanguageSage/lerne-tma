# Локальный классификатор CEFR

**Статус:** ✅ Активен и подключён к `api/ai_service.py`  
**Поддерживаемые языки:** 🇩🇪 Немецкий (DE). EN и NO — только AI.

---

## Что это такое и зачем

Когда пользователь нажимает «Классифицировать» в приложении, сервер должен определить уровень каждой фразы (A1–C1). Раньше **каждая фраза отправлялась в Gemini/GPT**: это занимало 3–8 секунд на запрос и стоило API-кредиты.

Этот модуль — **быстрый фильтр перед AI**. Он анализирует немецкую грамматику и лексику по правилам (без нейросети) и, если уверен в ответе, даёт результат мгновенно. В AI уходят только сложные или редкие фразы.

```
Фраза на DE
    │
    ▼
┌──────────────────────────┐
│  Локальный классификатор │  ← этот модуль
│  rules_de.py             │
│  vocabulary.py           │
│  scorer.py               │
└──────────┬───────────────┘
           │
    confidence ≥ 0.80?
           │
     ДА ───┤──── НЕТ
     │           │
     ▼           ▼
  Результат   Отправить
  мгновенно   в Gemini AI
```

## «Локально на сервере» — что это значит?

Приложение работает так:

```
Браузер пользователя
        │  HTTP запрос
        ▼
   Vercel Server
   (api/ai_service.py)   ← СЕРВЕР
        │
        ├── Локальный классификатор (Python, внутри сервера, память)
        │       └── Результат за < 1 мс ✅
        │
        └── Если нужно → Gemini API (внешний вызов)
                └── Результат за ~2–5 сек
```

**«Локально»** означает: **внутри вашего сервера Vercel**, без обращения к внешним API. Код написан на чистом Python, использует только словари и регулярные выражения — это те же технологии, что и сам FastAPI. Никаких тяжёлых библиотек (spaCy — 550 МБ — был отклонён именно поэтому).

## Какая грамматика включена

Модуль содержит **15 детекторов** немецкой грамматики. Каждый детектор — это набор регулярных выражений и/или словарных множеств.

### A1 — детектируется как базовый уровень
| Конструкция | Пример | Как детектируется |
|-------------|--------|-------------------|
| Modalverb Präsens | *Er **kann** schwimmen.* | Словарь: `{kann, muss, will, darf, soll, mag}` |

> **Примечание:** A1 — это «ничего сложного не найдено». Если ни один другой детектор не сработал, уровень = A1.

### A2 — ранние грамматические конструкции
| Конструкция | Пример | Уверенность |
|-------------|--------|-------------|
| Perfekt (haben) | *Ich **habe** ein Buch **gekauft**.* | 92% |
| Perfekt (sein) | *Er **ist** nach Berlin **gefahren**.* | 85% |
| Präteritum модальных | *Sie **konnte** nicht kommen.* | 90% |
| Reflexivverb (sich) | *Ich freue **mich**.* | 82–85% |
| Konjunktiv II höflich | *Ich **möchte** einen Kaffee.* | 88% |
| A2-Nebensatz | *Ich lerne, **weil** es wichtig ist.* | 88% |

Союзы A2-уровня: `weil, dass, ob, wenn, als`

### B1 — средний уровень
| Конструкция | Пример | Уверенность |
|-------------|--------|-------------|
| Plusquamperfekt | *Sie **hatte** das Formular **ausgefüllt**.* | 78% |
| Passiv Präsens | *Das Auto **wird repariert**.* | 82% |
| Passiv Präteritum | *Das Auto **wurde repariert**.* | 82% |
| Relativsatz | *Der Mann**, den** ich sah…* | 85% |
| um…zu | *…**um** in DE **zu** arbeiten.* | 85% |
| ohne…zu / statt…zu | *…**ohne** zu fragen.* | 88% |
| B1-Nebensatz | ***Obwohl** es regnet, gehe ich.* | 90% |
| Genitiv-Präpositionen | ***Wegen** des Regens…* | 80% |
| Konjunktiv II würde | *Ich **würde** gern helfen.* | 85% |

Союзы B1-уровня: `obwohl, während, nachdem, bevor, seitdem, sodass, solange, sobald, indem, sofern, falls`

Genitiv-предлоги: `wegen, aufgrund, mithilfe, anstelle, anlässlich, infolge, trotz, mangels, dank`

### B2 — продвинутый уровень
| Конструкция | Пример | Уверенность |
|-------------|--------|-------------|
| Passiv Perfekt | *Es ist **worden**.* | 90% |
| je…desto | ***Je** mehr ich lerne, **desto** besser.* | 92% |
| weder…noch | ***Weder** Kinder **noch** Erwachsene.* | 90% |
| sowohl…als auch | ***Sowohl** Theorie **als auch** Praxis.* | 90% |
| nicht nur…sondern auch | ***Nicht nur** Kinder…* | 85% |

### C1 — высокий уровень
| Конструкция | Пример | Уверенность |
|-------------|--------|-------------|
| sein + zu + Infinitiv | *Das Problem ist schwer **zu lösen**.* | 82% |
| sich lassen + Infinitiv | *Das **lässt sich** erklären.* | 88% |

## Как работает определение уровня слов (лексика)

Файл `data/vocab_de.json` содержит **~220 слов** с уровнями CEFR. При классификации модуль проверяет каждое смысловое слово фразы по этому словарю.

**Пример:**
```
Фраза: "Ich habe das Passwort falsch eingegeben."

Грамматика → A2 (Perfekt: habe + eingegeben)
Лексика:
  passwort → A2  ✅ найдено
  eingegeben → A2  ✅ найдено

Итог: max(A2, A2) = A2 ✅
```

**Важно:** лексика и грамматика **не суммируются** — берётся максимальный уровень из обоих.

## Как добавить новые слова

### 1. Открыть файл словаря
`api/services/classifier/data/vocab_de.json`

### 2. Добавить слово
```json
{
  "passwort": "A2",
  "kennwort": "A2",
  "новое_слово": "B1"   ← добавить сюда
}
```

**Правила:**
- Слово **только в нижнем регистре** (поиск идёт по lowercased токенам)
- Добавляйте и **основную форму** и **частые формы**: `{"eingeben": "A2", "eingegeben": "A2"}`
- Уровни: `"A1"`, `"A2"`, `"B1"`, `"B2"`, `"C1"`, `"C2"`

### 3. Влияние на производительность

| Размер словаря | Время поиска | Память |
|----------------|-------------|--------|
| 220 слов (сейчас) | ~0.01 мс | ~15 КБ |
| 2 000 слов | ~0.05 мс | ~120 КБ |
| 20 000 слов | ~0.2 мс | ~1.2 МБ |

**Вывод:** словарь можно расширять до **тысяч слов без ощутимого замедления**. Python `dict` — это хэш-таблица, поиск по ней O(1) независимо от размера.

> ⚠️ Словарь загружается **один раз** при первом обращении и кэшируется в памяти (`_VOCAB_CACHE` в `vocabulary.py`). Последующие запросы используют кэш — никаких повторных чтений с диска.

## Уровень уверенности (confidence) — что это

Каждый результат сопровождается числом от 0.0 до 1.0:

| Confidence | Что это значит |
|------------|----------------|
| **≥ 0.80** | Результат используется напрямую, AI не вызывается |
| **< 0.80** | Фраза отправляется в Gemini AI |
| **0.0** | Язык не поддержан или фраза пустая → AI |

**Как считается confidence:**
- Базовая: 1.0
- Средняя уверенность детектированных конструкций (например, je…desto = 0.92 → высокая)
- Штраф за неизвестные слова: −0.05 за 1 слово, −0.15 за 2, −0.25 за 4+
- Штраф за отсутствие грамматических признаков: −0.20

**Примеры:**
```
"Ich habe das Passwort falsch eingegeben."  → conf=0.94  → Локально ✅
"Er ist gestern nach Berlin gefahren."      → conf=0.74  → AI ↗
"Ich lerne Deutsch."                        → conf=0.75  → AI ↗
"Je mehr ich lerne, desto besser."          → conf=0.79  → AI ↗
```

> Короткие A1-предложения («Ich lerne Deutsch.») специально отправляются в AI — у них нет грамматических маркеров, и мы не уверены: это A1 или просто очень простая часть сложного текста.

## Файловая структура

```
api/services/classifier/
│
├── __init__.py          Экспортирует classify_sentence_fast()
│
├── pipeline.py          Оркестратор:
│                          1. detect_all_features_de(phrase)
│                          2. detect_vocabulary_level(phrase)
│                          3. calculate_result(grammar, vocab)
│
├── rules_de.py          15 грамматических детекторов.
│                        Использует: re (regex) + frozenset (O(1) lookup)
│                        Зависимости: ТОЛЬКО стандартная библиотека Python
│
├── vocabulary.py        Загружает vocab_de.json, сканирует смысловые слова.
│                        Кэширует словарь в _VOCAB_CACHE после первой загрузки.
│
├── scorer.py            Объединяет grammar_level + vocabulary_level:
│                          overall_level = max(grammar_level, vocabulary_level)
│                          confidence = f(feature_conf, unknown_words)
│
└── data/
    └── vocab_de.json    ~220 слов: lemma (lowercase) → "A2" | "B1" | "B2" | "C1"
```
