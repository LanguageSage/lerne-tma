# Тип: Puzzle (`type: "puzzle"`)

## WHEN TO USE
Сборка грамматически правильного предложения из перемешанных слов/токенов (тренировка порядка слов в главном и придаточном предложении, глагольной рамки, вопроса).

## FORMAT (`card.data`)
- `"tokens"` *(обязательно, `string[]`, минимум 1 элемент)* — массив токенов в **правильном исходном порядке**. Клиент сам перемешивает токены для ученика. Знаки препинания прикрепляются к соответствующему слову (например, `"ankam,"`, `"gegessen."`).
- `"translation"` *(необязательно, но рекомендуется, `string`)* — перевод собранного предложения (помещается на оборот карточки).

```json
{
  "id": "nachdem-puzzle",
  "type": "puzzle",
  "info": [
    {"type": "task", "text": "Bilden Sie einen korrekten Satz."}
  ],
  "data": {
    "tokens": ["Nachdem", "er", "gegessen", "hatte,", "ging", "er", "spazieren."],
    "translation": "После того как он поел, он пошёл гулять."
  },
  "explanation": "В придаточном с nachdem спрягаемый глагол hatte стоит в конце, а главное предложение начинается с глагола ging."
}
```

## VALIDATION
- `"type"` равен `"puzzle"`.
- Каждый элемент `"data.tokens"` — одно слово (со слитным знаком препинания, если он есть), **без пробелов внутри токена** и без символов `*`, `_`, `` ` ``.
- Токены в `"data.tokens"` записаны строго в правильном порядке предложения.
