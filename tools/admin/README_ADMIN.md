# 🛡️ Lerne TMA — Инструкция по работе с Админ-Панелью

Локальный модуль администрирования (`tools/admin/`) предназначен для удобного и безопасного управления пользователями, колодами и ИИ-перегенерацией без использования командной строки.

---

## 🚀 Быстрый запуск

Дважды кликните по файлу **`run_admin.bat`** в корневой папке проекта (или создайте ярлык на Рабочий стол).

Скрипт автоматически:
1. Поднимет локальный сервер на `http://127.0.0.1:8050`.
2. Откроет браузер с графической Панелью Администратора.

---

## 🌟 Ключевые возможности

### 1. 👥 Пользователи (`/api/admin/users`)
* Просмотр всех зарегистрированных пользователей в базе данных Supabase.
* Отображение общего количества колод в аккаунте каждого пользователя.

### 2. 📦 Все колоды (`/api/admin/decks`)
* **Поиск и фильтрация:** Поиск колод по названию или ID.
* **★ Дефолтные колоды:** Отметка колоды как «Дефолтная». Автоматически создает копии этой колоды для всех существующих и новых пользователей.
* **👥 Раздача группе пользователей:** Выбор нескольких пользователей чекбоксами и раздача колоды в виде:
  * *Персональных копий* (независимые копии в аккаунты).
  * *Совместного доступа (`Collaborator`)* к мастер-колоде.

### 3. ✨ ИИ-Перегенерация карточек (`/api/admin/decks/{deck_id}/regenerate`)
* Запуск высококачественной перегенерации в 1 клик.
* **Опции:** «Только пустые карточки», «Отключить озвучку (Edge-TTS)», «Dry-Run (тест)», «Ограничение количества».
* **Мониторинг:** Плавный Прогресс-бар (0–100%) и отображение подробных логов обработки каждой карточки в реальном времени.

---

## 🛡️ Гарантия изоляции
Файлы основного приложения (`/app/` и `/api/routers/`) не затрагиваются. Админ-панель работает как обособленный инструментарий и не деплоится на продакшн-сервер.
