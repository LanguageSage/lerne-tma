# 🛡️ Lerne TMA — Инструкция по работе с Админ-Панелью

Локальный модуль администрирования (`tools/admin/`) предназначен для удобного и безопасного управления пользователями, колодами и ИИ-перегенерацией без использования командной строки.

---

## 🚀 Быстрый запуск

Дважды кликните по файлу **`run_admin.bat`** в корневой папке проекта (или создайте ярлык на Рабочий стол).

Скрипт автоматически:
1. Поднимет локальный сервер на `http://127.0.0.1:8050`.
2. Откроет браузер с графической Панелью Администратора.

Админка доступна по `http://127.0.0.1:8050` и `http://localhost:8050` без входа.
Сервер принимает только loopback-соединения с этими точными `Host` (включая порт).
CORS разрешает только эти два origin; cookies и proxy-заголовки для доступа не используются.
Перед выполнением любого API проверяются `Origin`, либо локальный `Referer`, либо
`Sec-Fetch-Site: same-origin`. Посторонние/`null` origin и запросы `cross-site`/`same-site`
отклоняются, включая простые POST, загрузки файлов, GET-превью и скачивание бэкапов.
При отсутствии подтверждённого источника API возвращает 403. Для локальных CLI-скриптов
достаточно явно передать `Origin: http://127.0.0.1:8050`; интерфейс делает всё автоматически.
Встраивание админки во фрейм запрещено (`X-Frame-Options: DENY`).

Это защита от запросов сторонних страниц и DNS rebinding, а не аутентификация процессов
на компьютере. Локальные программы, расширения браузера и JavaScript самой админки
(включая загружаемые CDN-скрипты) остаются доверенными. Не публикуйте админку через
туннель или reverse proxy: локальный прокси может скрыть реальный адрес клиента.

Проверки:
```powershell
venv\Scripts\python.exe -m unittest scripts.tests.test_local_admin_security scripts.tests.test_author_router scripts.tests.test_structured_preview -v
```
Тесты используют SQLite в памяти и временные файлы, не рабочую БД.

## 🌟 Ключевые возможности

### 1. 👥 Пользователи (`/api/admin/users`)
* Просмотр всех зарегистрированных пользователей в базе данных Supabase.
* Отображение общего количества колод в аккаунте каждого пользователя.
* Быстрый переход к колодам выбранного пользователя в 1 клик.

### 2. 📦 Все колоды (`/api/admin/decks`)
* **Поиск и фильтрация:** Мгновенный поиск колод по названию, ID или языку.
* **★ Дефолтные колоды:** Отметка колоды как «Дефолтная».
* **👥 Раздача группе пользователей:** Выбор нескольких пользователей чекбоксами и раздача колоды в виде:
  * *Персональных копий* (независимые копии в аккаунты).
  * *Совместного доступа (`Collaborator`)* к мастер-колоде.
  * *Перенос в Библиотеку*.

### 3. 📦✨ Пакетная перегенерация нескольких колод (Batch Regeneration)
* **🔍 Накопление очереди через поиск:**
  1. Введите в поиске название колоды или тему (например, `A1`, `Borders`, `Reisen`).
  2. Нажмите кнопку **`➕ Отложить`** на нужной колоде.
  3. Введите в поиске следующую колоду и снова нажмите **`➕ Отложить`** (или выделите чекбоксами и нажмите **`📦 Отложить выбранные`**).
  4. Очередь сохраняется в браузере при смене поисковых запросов и вкладок.
* **📋 Плавающий док (Bottom Dock) и Менеджер очереди:**
  * Внизу экрана отображается компактный статус-бар с количеством отложенных колод, суммарным числом карточек и поддерживаемыми языками.
  * Кнопка **«📋 Список»** открывает окно управления очередью (статистика, число карточек без озвучки, удаление отдельных колод из пакета).
* **⚡ Массовая обработка пакета:**
  * **Массовая озвучка (TTS):** Фоновый синтез аудио для сотен карточек по всем отложенным колодам с изоляцией ошибок.
  * **Массовая ИИ-генерация:** Полная генерация контекстов, переводов и аудио с автоматическим созданием резервной копии перед запуском.
  * **🧪 Dry-Run тест пакета:** Быстрая генерация по 2 тестовые карточки на колоду с интерактивным предпросмотром и кнопкой «Сохранить результаты в БД».
  * **📊 Двойной прогресс-бар:** Отображение прогресса по колодам (1/10) и по карточкам (45/500), текущей обрабатываемой колоды и карточки.
  * **🎮 Управление:** Кнопки **«⏸ Пауза»**, **«▶ Продолжить»** и **«⏹ Стоп»**.

### 4. ✨ Одиночная ИИ-студия и Озвучивание карточек
* **🎙️ Перегенерация ТОЛЬКО озвучки (TTS):** Быстрая генерация качественного произношения (Edge-TTS) без изменения текстов и контекстов.
* **🔊 Предпрослушивание голосов (Voice Preview):** Кнопка «🔊 Превью» для живого тестирования любого диктора и темпа речи.
* **✨ Полная ИИ-генерация:** Высококачественная генерация текстов, переводов, контекстов и озвучки по выбранному системному промпту.
* **Опции:** «Только без озвучки», «Только пустые», «Только без контекста», «Синхронизация с копиями колод», «Dry-Run тест».

## 🛡️ Гарантия изоляции
Файлы основного приложения (`/app/` и `/api/routers/`) не затрагиваются. Админ-панель работает как обособленный инструментарий и не деплоится на продакшн-сервер.
