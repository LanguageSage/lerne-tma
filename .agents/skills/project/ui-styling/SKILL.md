# UI Styling Skill (Lerne TMA)

Guidelines for React 19 frontend UI/UX in `/app`.

## Instructions
- **Mobile-First & TMA Viewport**: Design for Telegram Mini App touch viewports (respect safe areas, Telegram main button, smooth touch feedback).
- **Animations**: Use `framer-motion` for micro-animations (card flips, swipe gestures, page transitions).
- **Icons & Typography**: Use `lucide-react` icons and clean, legible typography for language learning cards.
- **State & Props**: Keep transient UI state in local component state; use Zustand stores for global app/card state.
