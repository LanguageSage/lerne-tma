# Web Design Skill

Guidelines for visual aesthetics, color harmony, typography, and responsive UX design.

## Instructions
- Use dark mode palette with vibrant accents suitable for Telegram Mini Apps.
- Ensure high contrast ratios for readability of flashcards and quiz interfaces.
- Avoid cluttered layouts; use whitespace and clear visual hierarchy.
