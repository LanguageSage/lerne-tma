# Skill Creator Meta-Skill

Instructions for defining new reusable skill markdown documents.

## Instructions
- Create a subfolder under `.agents/skills/project/<skill-name>/` or `.agents/skills/harness/<skill-name>/`.
- Define a `SKILL.md` file with YAML frontmatter containing `name` and `description`.
- Keep instructions focused, practical, and specific to the codebase domain.
