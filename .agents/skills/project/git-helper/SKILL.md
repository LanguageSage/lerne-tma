# Git Helper Skill

Guidelines for formatting commits and managing Git branches in Lerne TMA.

## Instructions
- Use Conventional Commits format (`feat: ...`, `fix: ...`, `docs: ...`, `refactor: ...`).
- Never commit secret API keys or `.env` files.
- Keep commits atomic and focused on single logical changes.
