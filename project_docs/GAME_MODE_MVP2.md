# Game Mode MVP 2 — голосовой разговор

Доработка после тестирования (12 октября 2026): актуальные настройки, файлы и
результаты проверок — в [отчёте](GAME_MODE_MVP2_TESTING_FIXES.md).

Реализация в текущей ветке, без commit/push. Нет новых провайдеров, зависимостей,
миграций, игровых наград или изменений SRS/Knowledge. Каталог, доступность,
выдача, авторизация, лимиты и идемпотентность остаются на существующем сервере.

## Технологии и цикл

- STT: тот же `SpeechRecognition` / `webkitSpeechRecognition`, что используется
  в `StudyCardSpeech`, язык через `getSpeechLocaleForLang('de')`: `de-DE`.
  Код проверки карточки не используется: здесь нет эталона и оценки произношения.
- TTS: существующий Edge TTS через авторизованный `/media/generate-audio`,
  `getAudioUrl` и `useAudio`. Скорость берётся из настроек Lerne;
  `Bitte langsamer` применяет существующий `slow_speech`.
- AI: существующие `/game/attempts/{id}/turns`, configured_ai/AIService,
  серверный контекст и request_id/version. Ключи не передаются клиенту.

Кнопка «Включить голос» явно запрашивает разрешение через getUserMedia.
Полученные tracks сразу освобождаются: записью далее владеет браузерный STT.
Если включено автоозвучивание, звучит последняя реплика NPC; после успешного
окончания аудио и 350 мс для затухания звука запускается слушание.
По умолчанию реплика завершается вручную кнопкой «Завершить реплику»: паузы
не отправляют текст. В автоматическом режиме после выбранной паузы 2–5 с
(по умолчанию 4 с) вызывается stop(), затем ожидается onend и финальные результаты.
Если браузер сам завершил сессию, распознавание перезапускается через 350 мс
с сохранением фрагментов текущей реплики; такое onend само по себе не отправляет текст.
Результат отправляется существующим API, ответ отображается и озвучивается,
после чего цикл продолжается. Окончание выдачи книги не выключает свободный разговор.

Распознанный текст отображается и находится в поле ввода. Пустые результаты,
неокончательные результаты, результат без букв, слишком длинный текст и явно
низкая STT confidence не отправляются автоматически. Confidence используется
только для защиты отправки, не для оценки языка; значение 0 у некоторых движков
означает отсутствие оценки. Ошибочно распознанную, но уверенную осмысленную фразу
автоматически отличить от реальной речи невозможно.

Ручной режим включён по умолчанию. «Завершить реплику» отправляет завершённый
уверенный текст; при сомнительном или промежуточном результате сначала нужен
просмотр и ручная кнопка «Отправить». «Отменить реплику» очищает текст и ставит
микрофон на паузу. «Озвучивать ответы автоматически» действует также
на текстовые ответы. Режим, пауза и автоозвучивание хранятся локально; микрофон после перезагрузки
всегда выключен. Восстановленная история сама не озвучивается.

Пауза, выключение, переход к редактированию, новая попытка, уход со страницы и
скрытие вкладки освобождают STT, аудио и таймеры; TTS HTTP-запрос отменяется.
Поздние callback/results от старой сессии игнорируются. После ошибки нужен явный
повтор; AI-ошибка сохраняет текст и request_id для безопасной повторной отправки.
Есть предел ожидания разрешения 30 с, первоначального ожидания речи 45 с и
финализации stop 3 с. После получения текста 45-секундный таймер отключается.
Пять последовательных пустых сессий браузера приостанавливают распознавание.
Озвучивание имеет отдельный ограниченный watchdog с учётом длины текста.
По окончании 40 реплик остаётся существующий лимит попытки; нужен новый диалог.

## Голос и естественность NPC

Постоянный голос находится в `api/game_config/library.json`:
`npc.tts_voice = de-DE-KatjaNeural`. `/game/scene` возвращает это публичное поле.
Выбор другого голоса для карточек не меняет личность Frau Müller.

Паспорт NPC отделён от `scene.suggested_topic`; целевая книга остаётся только
серверным критерием результата. Общие правила NPC и AI-промпт явно следуют смене темы, не тянут посетителя к
балконной задаче, не требуют похвалы/вопроса после каждого ответа и используют
историю. Сомнительный смысл вызывает нейтральный переспрос вместо вопроса про
овощи. Серверные факты о книгах по-прежнему формулируются детерминированно.
Фактическая естественность зависит от настроенного AI-провайдера и модели.
MOCK остаётся помеченной ограниченной демонстрацией.

## Ручная проверка

1. Открыть авторизованный Game Mode в Chrome Windows на HTTPS или localhost
   с настроенным live AI. В MOCK естественность оценивать нельзя.
2. Включить голос, разрешить микрофон, дождаться немецкой реплики и индикатора
   ожидания. В ручном режиме завершать реплики кнопкой; в автоматическом — паузой. Например:
   «Ich wollen Gemüse auf Balkon», затем «Was machen Sie am Wochenende?» и
   «Bitte einfacher / Bitte langsamer». Проверить смену темы, контекст и голос.
3. В ручном режиме проверить несколько пауз внутри предложения и перезапуски
   браузера: отправка только после «Завершить реплику». В автоматическом режиме
   проверить паузы 2 и 5 с, короткое «Ja», молчание и фоновый шум.
4. Повторить ответ, остановить его, поставить разговор на паузу, выключить,
   включить снова, перейти на текст и уйти назад. Убедиться, что индикатор
   микрофона/звук исчезают и не возвращаются сами.
5. Отказать в разрешении, отключить сеть, повторить после восстановления;
   текст должен сохраняться, одна реплика не должна дублироваться.
6. Повторить на целевом мобильном браузере, проверить блокировку autoplay,
   доступность STT и работу наушников/динамика без захвата голоса NPC.

Web Speech API поддерживается не всеми браузерами; Chrome может отправлять
звук сервису распознавания браузера и требует сеть. Lerne не сохраняет исходные
записи. Реальное распознавание, звук Edge TTS, акустическое эхо и ответы live AI
не проверены автоматически. При заблокированном autoplay интерфейс ставит
разговор на паузу; доступна явная кнопка «Слушать» и текстовый ввод.
Справка: https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition
