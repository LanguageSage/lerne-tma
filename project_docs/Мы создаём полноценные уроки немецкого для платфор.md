Мы создаём полноценные уроки немецкого для платформы Lerne.

Цель — не просто объяснить грамматику, а провести ученика по цепочке:

понять → распознать → выбрать правильную форму → построить предложение → использовать в реальной речи → смешанная практика → контроль.

Для каждой грамматической темы создаём отдельную папку и примерно такие уроки:

1. `01 · Теория — подробно`
   Подробное объяснение темы на русском языке с немецкими примерами и переводом. Правила, логика, типичные ошибки, сравнения.

2. `02 · Теория — простыми словами`
   То же правило, но другим способом: интуитивно, без перегрузки терминами, через простые модели и повторяющиеся примеры.

3. `03 · Базовая практика`
   Простые упражнения только на основной механизм темы. Сначала не смешивать всё сразу.

4. `04 · Следующий уровень сложности`
   Зависит от темы: например, падежи, порядок слов, формы местоимений, предлоги и т. д.

5. `05 · Определение формы / смешивание основных правил`
   Ученик уже сам решает, какое правило или форму применять, без прямой подсказки.

6. `06 · Построение предложений`
   Соединение предложений, преобразование конструкций, самостоятельное построение правильной фразы.

7. `07 · Реальные ситуации`
   Практические ситуации из жизни: жильё, работа, покупки, курс немецкого, семья, транспорт и т. д. Здесь постепенно появляются открытые ответы.

8. `08 · Смешанная практика`
   Все изученные элементы темы вперемешку: Choice, Input, Puzzle, исправление ошибок, порядок слов и другие подходящие типы карточек.

9. `09 · Экзамен / контроль`
   Новые задания без подсказок и подробных объяснений. Проверяем, действительно ли ученик освоил тему.

Не каждая тема обязана иметь ровно 9 колод. Структуру можно адаптировать, но принцип должен сохраняться: от понимания к самостоятельному использованию.

ВАЖНО: перед созданием карточек всегда сначала проверять актуальные правила в репозитории:

`lerne-card-prompts`

Особенно:

* `AGENTS.md`
* `common.md`
* `validation.md`
* нужные `types/*.md`

Использовать только актуальный синтаксис карточек.

Текущий базовый контракт:

* `FRONT:` — упражнение
* `BACK:` — перевод всей обрабатываемой немецкой фразы; для `@free` — Musterlösung
* `CONTEXT:` — короткое грамматическое объяснение
* внутри FRONT использовать `::task`, `::source`, `::options`, `::example`, `::exercise`
* разделитель между карточками: `<<<LERNE_CARD>>>`
* Choice: `{*правильный|вариант|вариант}`
* Input: `[[ответ]]`
* Puzzle: `@puzzle`
* Free Text только для действительно открытых заданий: `@free`

Не использовать старый синтаксис, если он противоречит `lerne-card-prompts`.

Карточки должны быть пригодны для прямого массового импорта в Lerne.

Главный педагогический принцип:
не заставлять ученика просто зубрить таблицы. Сначала показать логику, затем дать много коротких тренировок, а потом заставить самостоятельно определить форму и использовать её в речи.

Для A2 особенно важно:

* короткие и понятные немецкие предложения;
* бытовая лексика;
* постепенное увеличение сложности;
* не смешивать соседние грамматические темы слишком рано;
* давать перевод там, где он помогает понять смысл;
* делать примеры полезными для реальной жизни в Германии.

Если я называю новую тему A2, сначала предложи структуру папки/уроков для этой темы, а затем последовательно создавай колоды.
