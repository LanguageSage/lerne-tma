Сейчас в приложении используется классический математически строгий алгоритм **Тасования Фишера — Йетса (Fisher-Yates shuffle)**:

### 1. Как устроен алгоритм ([`app/src/utils/shuffle.js`](file:///c:/121/Lerne_projekt/tma/app/src/utils/shuffle.js))
1. Берётся копия массива элементов.
2. Проход идёт с конца массива к началу: на каждом шаге $i$ выбирается случайный индекс $j$ из диапазона $[0, i]$.
3. Элементы с индексами $i$ и $j$ меняются местами.
4. Выбранный элемент фиксируется и больше в розыгрыше не участвует.

### 2. Где и как применяется:

* **Выбор карточек в билет ([`useLidStore.js`](file:///c:/121/Lerne_projekt/tma/app/src/store/useLidStore.js)):**
  * Массив всех доступных карточек темы полностью и честно перемешивается алгоритмом Фишера — Йетса, после чего берутся первые $N$ штук (`slice(0, count)`: 10 вопросов по каждому из 3 блоков и 3 вопроса по федеральной земле).
  * Каждая карточка в пуле теперь имеет **строго равную вероятность** выпадения ($\frac{1}{N}$).

* **Перемешивание вариантов ответа ([`lidCardAdapter.js`](file:///c:/121/Lerne_projekt/tma/app/src/utils/lidCardAdapter.js)):**
  * Варианты ответов карточки прогоняются через `shuffleFY`. Правильный ответ попадает на позиции **A**, **B**, **C** или **D** с равной вероятностью в **25%** (отклонение не превышает 0.2%).

* **Серверный бэкенд ([`api/routers/lid.py`](file:///c:/121/Lerne_projekt/tma/api/routers/lid.py)):**
  * Для онлайн-запросов используется встроенный `random.sample()`, работающий по такому же принципу равномерной выборки без возвращения.

### 2. Считается ли Фишер — Йетс хорошим алгоритмом?

**Это не просто «хороший» алгоритм — это мировой золотой стандарт в Computer Science** для задач случайного перемешивания.

Почему именно он:
1. **Математическое совершенство (Uniform Distribution):** 
   Для массива длины $N$ существует ровно $N!$ (факториал) возможных перестановок. Алгоритм Фишера — Йетса гарантирует, что каждая из $N!$ перестановок генерируется с **абсолютно одинаковой вероятностью** $\frac{1}{N!}$.
2. **Отсутствие смещения (Zero Bias):**
   В отличие от наивных методов (вроде `sort(() => Math.random() - 0.5)`), где движок JavaScript оптимизирует сравнения и ломает теорию вероятностей, в Фишере — Йетсе каждый элемент перемещается ровно один раз на независимую позицию.
3. **Максимальная производительность:**
   Сложность алгоритма — линейная $O(N)$ по времени и $O(1)$ по дополнительной памяти. Это самый быстрый из возможных алгоритмов перемешивания без потери качества случайности.
