# Описание Пользовательских Данных и Форматов (User Files)

В данном документе описана структура пользовательских данных, схема хранения карточек, папок и кэширования в **Lerne TMA**.

---

## 🗃 Пользовательские Сущности

### 1. Профиль Пользователя (`TMAUser`)
- `user_id`: Уникальный ID пользователя Telegram (BigInt).
- `first_name`, `last_name`, `username`, `photo_url`: Профиль Telegram.
- `active_language`: Активный целевой язык (`de`, `en`, `no`).
- `has_selected_language`: Флаг прохождения модального окна выбора языка (`true` / `false`).
- `is_guest`: Флаг гостевого режима.

### 2. Колоды (`TMA_Deck`)
- `id`: Уникальный идентификатор колоды.
- `user_id`: Владелец колоды.
- `name`: Название колоды (например, "Разговорные фразы B1").
- `target_language`: Целевой язык (`de`, `en`, `no`).
- `folder_id`: ID родительской папки (если есть).
- `position`: Порядковый номер для сортировки.
- `is_pinned`: Закреплена ли колода вверху экрана.

### 3. Карточки (`TMA_Card`)
- `id`: Уникальный идентификатор карточки.
- `deck_id`: Привязанная колода.
- `front_text`: Текст лицевой стороны (слово/фраза на иностранном языке).
- `back_text`: Текст обратной стороны (перевод).
- `context`: Дополнительный контекст или пример предложения.
- `audio_url`: Ссылка на аудио-файл озвучки.
- `image_url`: Ссылка на изображение.

### 4. Прогресс Повторений (`TMAProgress`)
- `user_id`, `card_id`: Комбинированный первичный ключ.
- `ease_factor`: Коэффициент легкости (по умолчанию 2.5).
- `interval`: Текущий интервал повторения в днях.
- `repetitions`: Количество успешных повторений подряд.
- `next_review`: Дата и время следующего повторения.
- `queue`: Текущая очередь (`new`, `learning`, `review`).

---

## 📦 Формат Кэша в `LocalStorage`

На клиенте кэшируются следующие ключи:
- `lerne_user_id`: Идентификатор текущей сессии.
- `lerne_target_language`: Выбранный язык (`de`, `en`, `no`).
- `lerne_has_selected_language`: Строка `'true'`, если язык выбран.
- `lerne_init_cache`: JSON-строка последнего ответа `/api/init` для мгновенного отрисовывания UI до ответа сети.
- `lerne_init_cache_version`: Версия кэша (для автоматической инвалидации устаревших ответов).
