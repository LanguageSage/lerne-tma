# Game Mode MVP 1 — Stadtbibliothek

Реализован 11 октября 2026 года в текущей ветке, без commit/push.

## Запуск

Локальное приложение: http://127.0.0.1:5173. Войти в существующий аккаунт Lerne,
затем на главном экране выбрать **Game Mode · Stadtbibliothek**. Немецкий диалог
не зависит от выбранного языка Classic; интерфейс поддерживает RU/EN/UK.

В этой сессии API и Vite запущены на портах 8001 и 5173. Для следующего запуска
из корня проекта в двух терминалах PowerShell:

```powershell
& .\venv\Scripts\python.exe -m uvicorn api.main:app --host 127.0.0.1 --port 8001
```

```powershell
npm --prefix app run dev -- --host 127.0.0.1 --port 5173
```

Используется существующий `venv`: в системном Python отсутствует объявленный
`python-telegram-bot`, а в проектном окружении зависимости доступны. На новом
окружении установить существующий `api/requirements.txt`; новые зависимости
для Game Mode не добавлены. Vite уже проксирует `/api` на локальный порт 8001.

## ИИ и данные

Game Mode использует текущие серверные `AI_PROVIDER`, `DEFAULT_MODEL`/`AI_MODEL`
и ключ выбранного провайдера из существующих настроек. В этой среде проверен
Google с моделью `gemini-3.5-flash-lite`. Ключи не входят в ответы Game API и не
передаются в браузер. Никаких новых ключей не создавалось.

Если провайдер/модель не настроены, экран показывает понятное состояние.
Для отдельной разработки можно перед запуском API установить
`$env:GAME_MODE_MOCK = '1'`: появится явная отметка MOCK; это ограниченный
детерминированный сценарий. При `ENVIRONMENT=production` mock игнорируется.

Новая таблица `tma_game_attempt`, миграция **87**, применена к настроенной
PostgreSQL-базе. Проверены наличие таблицы, включённый RLS и отсутствие SELECT
для публичных ролей `anon`/`authenticated`. При проверке таблица не содержала
записей: тестовые разговоры с реальной моделью не сохранялись в пользовательские
данные. Через API доступ возможен только с существующим Bearer-токеном владельца.
Изменений данных/алгоритмов прогресса Classic нет.

Миграция также запускается при старте backend; повторный запуск безопасен.
Отдельная команда: `& .\venv\Scripts\python.exe -m api.game_migration`.
RLS и отсутствие публичных политик соответствуют доступу через собственный
FastAPI backend, а не через Supabase Auth JWT. См. [официальную документацию по защите Data API](https://supabase.com/docs/guides/api/securing-your-api).

## Что работает

- Frau Müller с отдельным паспортом, временным SVG-портретом и фиксированным каталогом пяти книг.
- Свободный текст, контекст разговора, короткие уточняющие вопросы, разговор вне основной задачи.
- Серверный подбор по теме/опыту/месту, проверка наличия и выдача. Ошибочная грамматика не штрафуется.
- История текущего разговора, повтор последней реплики без обращения к AI, подсказка и новый разговор.
- Просьбы объяснить проще, повторить и говорить медленнее; озвучивание через существующий TTS/плеер.
- Сохранение исхода, подсказок, уточнений, дат и ограниченного контекста; восстановление текущей попытки в том же браузерном сеансе.
- Лимиты расходов, таймауты, защита от повторной отправки и параллельных изменений; сохранение текста при ошибке.

Целевая задача — получить книгу для начинающего, который хочет выращивать овощи
на небольшом балконе. Достаточно объяснить смысл; точная готовая фраза не требуется.
При ясном запросе на выдачу подходящей книги задача завершается сразу; при поисковом
вопросе NPC сначала предлагает книгу и ждёт согласия. Другая доступная книга даёт
`other_book`, отсутствующая/занятая не выдаётся. Перезапуск не меняет каталог.

AI извлекает намерение, но не возвращает авторитетный ID книги или результат.
Выбор/наличие/выдачу определяет сервер; соответствующие реплики построены из его
фактов. Остальные реплики генерирует модель с паспортом NPC, состоянием и историей.

## Проверки и фактические ограничения проверки

- **45 backend-тестов PASS**: 18 новых Game Mode и 27 существующих answer evaluation.
  Команда: `python -m unittest tests.test_game_mode tests.test_answer_evaluation -q`.
  В тестах используются изолированная SQLite в памяти и подменённый AI; рабочая БД не меняется.
- **8 browser-тестов PASS**: 5 Game Mode и 3 существующих guest-entry.
  API подменён, внешние вызовы заблокированы. Проверены восстановление истории,
  повтор/подсказка/новый разговор, сбои AI/TTS, сохранение draft/request ID, вход и Back.
- Проверены RU/EN/UK при ширинах **320, 375, 430, 768, 1280px**, отсутствие горизонтального
  переполнения и высота кнопок не менее 44px. Скриншоты desktop success и mobile unconfigured
  просмотрены; автопрокрутка ограничена историей и не сдвигает весь экран.
- **Полный ESLint PASS**, **Vite build PASS**, изменённые Python-файлы скомпилированы.
  Сборка показывает существующие предупреждения о больших чанках/смешанных импортах.
- Общий frontend-набор: **244/247 PASS**, три ошибки в неизменённом `exerciseParsers.test.js`:
  bulk-import level (`''` вместо `B1`), сохранение ручного перевода, несколько синонимов в choice gap.
  Этот тест и все импортируемые им модули совпадают с HEAD; Game Mode их не меняет.
- Реальный Google: корректный запрос и запрос с ошибками дали `success`; вопросы вне задачи,
  объяснение проще, отсутствующая и занятая книга, неясный запрос дали ожидаемые результаты.
  Проверена последовательность уточнений, отказа и повторного запроса до выдачи.
- Реальный backend запущен; проверены HTTP 200 у frontend и HTTP 401 `authentication_required`
  у Game API напрямую и через Vite без входа. Полный импорт API в проектном venv успешен.
  UI с реальным пользовательским входом и реальное воспроизведение TTS вручную не проверялись.

## Ограничения MVP

- Одна сцена и один NPC; только немецкий, текстовый ввод, без микрофона.
- Game Mode требует интернет; офлайн-механика Classic остаётся прежней.
- Подтверждения каталога/выдачи имеют фиксированную формулировку ради согласованности мира.
  Семантическое понимание остальных реплик зависит от качества выбранной модели.
- Контекст хранения — последние 24 сообщения; AI получает последние 12. Полного архива нет.
- 40 ходов на попытку, 20 новых попыток и 120 зарезервированных AI-вызовов в сутки UTC;
  не более двух вызовов на ход, 25 секунд, 400/250 выходных токенов. Это не денежный бюджет.
- Нет языка/мастерства/XP-оценивания, связи с Knowledge/SRS или экрана сравнения попыток.
- Пока нет автоматического срока хранения/удаления разговоров. TTS зависит от текущего сервиса.

## MVP 2

Сначала собрать реальные разговоры добровольных тестировщиков и проверить семантику/задержки
на выбранной модели. Затем добавить просмотр и удаление попыток со сроком хранения,
сравнение решения одной задачи через время и второй NPC через конфигурацию. Голосовой ввод
стоит выделять из текущего карточного компонента только после проверки спроса; общую модель
навыков Classic/Game подключать отдельным согласованным изменением.
