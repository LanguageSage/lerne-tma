## При этом библиотека остаётся общей

Допустим, мы сделали качественную колоду «Как выразить своё мнение».

Она полезна и для DTZ, и для Goethe, и для telc. Зачем создавать её три раза? Не нужно.

А вот «Презентация по пяти пунктам» будет относиться к Goethe B1. Ученик DTZ сможет найти её в библиотеке, но она не должна быть обязательной частью его подготовки.

Для этого у каждой колоды в паспорте можно предусмотреть два признака: «общая для B1» и «для каких экзаменов применяется».

И ещё одно важное решение: наш текущий TASK с приоритетом DTZ — это план производства контента, а не маршрут, обязательный для каждого пользователя.

Я бы сохранил именно такую архитектуру. Она позволит нам сейчас сосредоточиться на твоём DTZ, одновременно создавая общие качественные уроки для всех пользователей Lerne. Не нужно сразу программировать сложную систему — сначала правильно организуем учебный материал.
