## 1. Общий обзор и назначение

**Lerne TMA** — это приложение интервального повторения нового поколения, интегрированное напрямую в Telegram Mini Apps (TMA). 

Приложение спроектировано для **интенсивного изучения иностранных языков** и решения проблемы забывания материала. Приложение совмещает:
- Мобильный интерфейс с плавными анимациями (Framer Motion).
- Умный алгоритм повторений (SuperMemo 2).
- Автоматическое генерирование примеров и контекста через нейросетевые модели (Gemini / OpenAI).
- Нейронное озвучивание текста в реальном времени.

## 2. Архитектура и стек технологий

| Слой | Технологии | Назначение |
| :--- | :--- | :--- |
| **Frontend** | React 19, Vite, Zustand, Framer Motion, Lucide Icons | Пользовательский интерфейс, состояние, анимации 60 FPS |
| **Offline Storage** | Dexie.js (IndexedDB) | Полностью независимая локальная база данных для оффлайн-работы |
| **Backend** | Python 3.12, FastAPI, Peewee ORM | REST API, алгоритмы расчета SRS, бизнес-логика |
| **База данных** | Supabase (PostgreSQL) + SQLite (`lerne.db`) | Облачное хранилище профилей, карточек и совместных папок |
| **Audio Service** | Edge-TTS (Microsoft Neural Voices) | Высококачественная нейросетевая генерация речи |
| **Platform** | Telegram WebApp SDK | Синхронизация с Telegram CloudStorage, кнопка «Назад», вибрация (Haptics) |

## 3. Мультиязычность и выбор родного языка

В Lerne TMA реализована двоякая языковая система:

1. **Native Language (Родной язык пользователя)**:
   - Определяет язык интерфейса (подписи, меню, кнопки, обучающие подсказки).
   - При первом входе выводится специальный модальный диалог (`LanguageWelcomeModal`) для выбора родного языка (Русский, English, Deutsch и др.).
2. **Target Language (Изучаемый язык)**:
   - В верхней части экрана доступен переключатель изучаемого языка (например, 🇩🇪 DE, 🇬🇧 EN, 🇳🇴 NO).
   - **Строгая изоляция контента**: при выборе немецкого языка показываются только папки и колоды, привязаные к немецкому языку.
   - ИИ-генерация предложений и озвучка авто-настраиваются под выбранный целевой язык.

## 4. Иерархия контента: Папки и Колоды

Контент пользователя организован по древовидной системе:

- **Папки (Folders)**:
  - Служат для группировки колод по темам (например, *"Грамматика B1"*, *"Разговорный немецкий"*).
  - Поддерживают вложенность, цветовые иконки и статус совместного доступа.
- **Колоды (Decks)**:
  - Содержат наборы карточек.
  - Каждая колода отображает счетчики карточек по статусам:
    - 🔴 **New**: карточки, которые пользователь еще ни разу не учил.
    - 🟡 **Learning**: карточки в процессе заучивания.
    - 🟢 **Due**: карточки, срок повторения которых настал сегодня по алгоритму SRS.

## 5. Режимы обучения (Study & Trainer Modes)

В приложении предусмотрено **несколько специализированных режимов** для разностороннего запоминания слов.

### 5.1. Классическое повторение SRS (`StudyView`)
- Пользователь видит переднюю сторону карточки (слово или выражение).
- Нажатие на карточку или кнопку «Показать перевод» запускает 3D-переворот.
- На обратной стороне отображается:
  - Точный перевод и транскрипция.
  - Примеры предложений с выделением изучаемого слова.
  - Грамматические пометки (род существительного, формы глаголов).
- Низу расположены 4 кнопки оценок алгоритма SM-2.

### 5.2. Тренажер предложений / Пропусков (`TrainerView` & `StudyCardPuzzle`)
- Если карточка содержит конструкцию с фигурными скобками (например: `"Ich {habe} einen Hund"`), приложение автоматически переключает ее в **режим пазла / заполнения пропусков**.
- Пользователь должен составить предложение из плашек со словами или вписать пропущенное слово.
- Идеально подходит для отработки грамматических конструкций и порядков слов.

### 5.3. Режим речевого ввода (`StudyCardSpeech`)
- Использует Web Speech API или микрофон устройства.
- Пользователь произносит ответ голосом. Система распознает речь, сравнивает произнесенную фразу с оригиналом и оценивает точность произношения.

### 5.4. Режим тестов / Квизов (`StudyCardQuiz`)
- Отображает вопрос и 4 варианта ответа (один правильный, три дистрактора).
- Позволяет быстро проверить пассивный словарный запас.

## 6. Интервальные повторения (Алгоритм SM-2)

Алгоритм расчёта интервалов повторения основан на классической математической модели **SuperMemo 2**:

- **Оценки пользователя**:
  - `1` / **Again (Сброс)**: Пользователь не помнит слово. Карточка отправляется в конец текущей сессии, а интервал сбрасывается до 1 дня.
  - `2` / **Hard (Трудно)**: Слово вспомнили с трудом. Интервал увеличивается незначительно (коэффициент $\approx 1.2$).
  - `3` / **Good (Хорошо)**: Оптимальное повторение. Интервал умножается на текущий `Ease Factor`.
  - `4` / **Easy (Легко)**: Слово усвоено отлично. `Ease Factor` увеличивается, интервал растет с ускоренным коэффициент.
- **Factor легкости (Ease Factor)**: Стартовое значение $EF = 2.5$. Автоматически корректируется при каждом ответе на основе сложности карточки.

## 7. Нейронная озвучка (TTS) и Караоке-подсветка

- **Edge-TTS**: Произношение генерируется нейронными дикторами Microsoft (например, `de-DE-ConradNeural`, `en-US-AnaNeural`).
- **Караоке-подсветка (`KaraokeText.jsx`)**: При воспроизведении примера предложения приложения подсвечивает текущее звучащее слово синхронно с аудиопотоком.
- **Аудио-плеер**: Включает регулировку скорости воспроизведения ($0.75x$, $1.0x$, $1.25x$) и возможность авто-воспроизведения при открытии карточки.

---

## 8. ИИ-Ассистент и генерация карточек

При добавлении нового слова пользователь может воспользоваться **ИИ-генератором**:
1. Отправляет запрос к модели (Gemini / OpenAI API).
2. Нейросеть автоматически заполняет:
   - Перевод на родной язык.
   - Транскрипцию и IPA-фонетику.
   - 2-3 живых примера предложений уровня A1-C1.
   - Формы слова (для немецкого: род $der/die/das$, множественное число, 3 формы глагола).
3. Позволяет создавать карточки в 1 клик без ручного ввода словарей.

## 9. Совместная работа и шеринг (Collaborative Folders)

- **Шеринг колод**: Каждая колода или папка имеет уникальную ссылку-приглашение (`shareId`).
- **Совместные папки**: Пользователи могут делиться папками с друзьями или учениками.
- **Фоновая синхронизация (`useCollaborativeSync`)**: Автоматически обновляет карточки в колоде при внесении изменений владельцем или соавторами.

---

## 10. Оффлайн-режим и локальная БД (Dexie.js / IndexedDB)

- **Local-First Подход**: При отсутствии сети приложение считывает и записывает все данные в IndexedDB в браузере.
- **Фоновая рассинхронизация**: При восстановлении интернет-соединения локальные изменения автоматически отправляются на Supabase сервер.

---

## 11. Управление дубликатами и Корзина (Trash Manager)

- **Менеджер дубликатов (`DuplicateManager.jsx`)**: Автоматически сканирует колоды на наличие одинаковых слов и предлагает объединить или удалить дубли.
- **Корзина (`TrashManager.jsx`)**: Удаленные карточки и колоды не теряются безвозвратно, а помещаются в Корзину, откуда их можно восстановить в любой момент.

---

## 12. Интеграция с Telegram UI & Навигация

- **Native BackButton**: Использует физическую/экранную кнопку «Назад» в Telegram для плавного закрытия модальных окон и возврата по дереву папок.
- **Haptic Feedback**: Тактильный отклик (вибрация смартфона) при перевороте карточек, нажатии на оценки и правильных ответах в тренажере.
- **Telegram CloudStorage**: Данные авторизации и пользовательские предпочтения дублируются в облако Telegram.
