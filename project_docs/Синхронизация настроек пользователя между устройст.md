Синхронизация настроек пользователя между устройствами
Описание изменений
Реализована полноценная поддержка синхронизации настроек между всеми устройствами пользователя (смартфон, ноутбук, планшет, Telegram Mini App, Standalone Web).

Ключевые доработки:
Поддержка авторизации пользователей Telegram:

В 
useSettingsStore.js
 функции debouncedSaveSettings и saveCurrentSettingsToServer теперь проверяют getAccessToken() || getUserId(). Пользователи Telegram TMA, авторизованные по ID (через заголовок X-User-ID), теперь гарантированно сохраняют свои настройки в базу данных.
Включение языка интерфейса в пакет настроек:

Язык интерфейса (native_language) включён в collectUserSettings, а при получении настроек с сервера (syncUserSettingsFromServer) автоматически применяется через модуль локализации 
locale.js
.
В 
i18nContext.jsx
 смена языка инициирует синхронизацию настроек в профиле.
Синхронизация на лету при возвращении во вкладку / онлайн:

В 
useSettingsStore.js
 добавлен метод fetchUserSettingsFromServer(), который проверяет отсутствие несохранённых локальных изменений (saveTimer === null), запрашивает /user/settings и обновляет стор и локальное хранилище.
В 
useAppInitialization.js
 хук вызывает fetchUserSettingsFromServer() при наступлении событий visibilitychange (пользователь вернулся во вкладку приложения) и online (восстановление интернет-соединения). Изменения, сделанные на телефоне, сразу применяются на ПК без необходимости полной перезагрузки страницы.
Исправление в бэкенде:

В 
settings.py
 объявлен экземпляр logger = logging.getLogger(__name__), предотвращающий возможные NameError при логировании ошибок.
