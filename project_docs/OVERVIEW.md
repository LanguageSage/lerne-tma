# Обзор проекта Lerne TMA (Overview)

## 📌 Что такое Lerne TMA?

**Lerne TMA (Telegram Mini App)** — это автономное высокопроизводительное веб-приложение для эффективного изучения иностранных языков с помощью карточек интервального повторения (SRS), работающее прямо внутри мессенджера Telegram.

Приложение сочетает мобильный UX, анимации 3D-переворотов карточек, аудио-озвучку, генерацию примеров с помощью ИИ и мгновенную синхронизацию с облаком.

---

## 🎯 Ключевые Возможности Программы

1. **Интервальные Повторения SM-2 (SRS)**:
   - Автоматический расчет интервалов следующего повторения на основе оценки легкости воспоминания карточки (`Ease Factor`).
   - Автономный подсчет карточек в очередях (`new`, `learning`, `due`).

2. **Мультиязычная Изоляция (DE 🇩🇪, EN 🇬🇧, NO 🇳🇴)**:
   - Полная изоляция пространства: колоды, папки и промпты ИИ разграничены по языкам обучения.
   - Возможность переключать целевой язык в 1 клик на главном экране.

3. **Telegram CloudStorage & DB Sync**:
   - Автоматическое сохранение статуса выбора языка и профиля пользователя в облаке Telegram и PostgreSQL (Supabase DB).
   - Приложение мгновенно запускается на iOS, Android и Desktop Telegram без сброса настроек.

4. **Генерация Контекста через ИИ**:
   - Автоматическая генерация примеров предложений, перевода и контекста для карточек с помощью моделей Google Gemini / OpenAI.
   - Персональные промпты под каждую языковую категорию.

5. **Озвучка (Text-to-Speech)**:
   - Высококачественная нейронная озвучка слов и фраз через Edge-TTS под разные языки (`de-DE-ConradNeural`, `en-US`, `ru-RU`).

---

## 🏗 Краткий архитектурный очерк

- **Фронтенд**: React 18, Vite, Zustand, Framer Motion, Telegram Mini App SDK.
- **Бэкенд**: FastAPI (Python 3.12), Peewee ORM, PostgreSQL (Supabase).
- **Деплой**: Vercel Functions (`/api/*` endpoints).
